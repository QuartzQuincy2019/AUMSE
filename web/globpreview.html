1位置形态独立 / 上形 / 中形 / 下形

同一码位在词的不同位置取不同字形，对应竖排的上、中、下与独立成字。 下面用零宽连接符把字形强行逼到指定形态： 字母后面接 ZWJ → 它「右边有人」→ 取上形； 前面接 ZWJ → 取下形；前后都接 → 中形；两侧不接 → 独立形。

2元音组合矩阵8 × 8，行 × 列

行是前一个元音、列是后一个元音，单元格里渲染这一对。 用下面的「上下文」切换，看同一对处在不同位置时是否长出不同字形。 悬停能看到这一对的实际行宽（与两字各自中形的行宽之和比较）—— 那只是线索，不是判据。

3借词辅音阿礼嘎礼字母

鲍培表第二栏的 f k h lh dz ts zh ch sh rh 是借词辅音， 为转写汉语、藏语、梵语借词而设。 其中 zh / ch / sh / rh 四个是「基字 + 下加的 r」（ᠷ U+1837） —— 字形上看就是基字下面再接一笔 r 的转角，依次是 Ƶ 1841、Ç 1842、 Š 1831、Ʒ 183F。 lh 例外，它是「l + 小 h」（U+1840）。 注意别拿预组合的 1841 ZHI／1842 CHI／183F ZRA 当这四个字 —— 它们都比手写稿少了下面那笔 r。

4元音 + 自由变体选择符FVS1–4

同一个元音码位，后接 FVS 可以指定用哪一种字形变体。 词中的 a / e 常常同形，靠的就是这一列区分。 如果某一格的 FVS 自己画出了方框占位符，说明这支字体没有把它当成 变体选择符「吃掉」，而是照常画了字形 —— 那也是需要记录的信息， 换字体时对比一下就知道是不是字体行为。

怎么用这张表
  • 形态由字体决定：同一串在不同字体里可能给出不同结果， 所以顶部留了字体切换（内置 Noto / 本机 Baiti），方便对照。
  • ZWJ / ZWNJ 不占位：U+200D 让两侧连上， U+200C 让两侧断开。它们不出字形，只影响形态选择。
  • 行宽只是线索：连字通常会让推进量变小，但形态变化本身也会改变宽度。 所以这一页不替你判定「有没有合形」，只把宽度差放在悬停提示里。
  • 竖排才是本来的排法：横排按钮只是方便扫读，横排下字形仍是竖式设计的，看着会「躺倒」。
