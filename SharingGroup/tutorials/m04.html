指针初步

UME 项目组内部教程 · M04（Main） · 面向零编程基础成员

C 本讲：指针

开始之前

很多人被「指针」这个词吓住，其实它一点也不神秘。

如果你看懂了M03第 9 节的「地址」—— 变量住在有编号的房间里，& 能问出房间号 —— 那么指针就只是一句话的事。

本讲的代码与输出全部均使用 g++ 13.1.0（-std=c++17）实际编译运行核对。 文中所有箭头图都表示「指向」，鼠标移上去有反馈。

1一句话认识指针

回想M03：每个变量都有自己的地址（房间号），&a 就能取到。

那么问题来了：既然地址就是一个数，能不能把它存进一个变量里？

能。这种「专门用来装地址的变量」，就叫指针。

指针的定义

指针 = 一个变量，它里面装的是另一个变量的地址。

就这么简单。它不是魔法，也不是什么高级技巧， 只是「内容是地址」的普通变量。

画成图看

执行这两行之后：

一个最简单的指针复制
int x = 42;        /* 普通变量：装了一个数 42 */
int *p = &x;       /* 指针变量：装了 x 的地址 */
内存里的样子（箭头表示「指向」）
变量 x
42
◀─── p 指向这里 ───
指针 p
x 的地址

理解这张图的两个要点：

  • x 的盒子里装的是 42（一个数）
  • p 的盒子里装的是 x 的地址（不是 42）。 但我们说「p 指向 x」，因为顺着 p 里的地址就能找到 x
记住这个比喻： x 是一间房，42 是房里住的人。
p 是一张纸条，上面写着「x 的房间号」。
纸条上写的不是「42」，而是「去哪里找 42」。

2两个符号：& 和 *

学指针只需要两个符号，它们的作用正好相反：

符号读作作用例子
&取地址 给我这个变量的地址&x → x 的地址
*解引用
（取值）		 顺着这个地址，把里面的东西拿出来*p → p 指向的那个值
用「箭头」来想 *

*p 的意思是：从 p 出发，顺着箭头走到它指向的房间，把里面的东西取出来。

你可以把 * 读成「顺着箭头走到……」。

完整例子：取值与改值复制
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;              /* p 指向 x */

    printf("x     = %d\n", x);
    printf("&x    = %p\n", (void *)&x);
    printf("p     = %p   （p 里装的就是 &x）\n", (void *)p);
    printf("*p    = %d   （顺着 p 找到 x）\n", *p);

    /* 通过指针改 x —— 注意改的是 x，不是 p */
    *p = 99;
    printf("执行 *p = 99 之后：x = %d\n", x);

    /* 反过来，改 x 也能从 *p 看见 */
    x = 7;
    printf("执行 x = 7 之后：*p = %d\n", *p);
    return 0;
}
运行结果（地址每次都会变）
x     = 42
&x    = 000000000060FD74
p     = 000000000060FD74   （p 里装的就是 &x）
*p    = 42   （顺着 p 找到 x）
执行 *p = 99 之后：x = 99
执行 x = 7 之后：*p = 7

注意 p 和 &x 打印出来一模一样 —— 这直接证明了「p 里装的就是 x 的地址」。

而后两行更重要，它说明一件事： x 和 *p 是同一个房间。 从哪个门进去改，另一个门看到的都变了。

3声明一个指针

语法就是在类型后面加一个 *：

指针声明语法复制
类型 *变量名;      /* 例：int *p;   读作「p 是一个指向 int 的指针」 */
写法含义
int x;一个整数
int *p;一个指针，它指向一个整数
double *q;一个指针，它指向一个小数
char *s;一个指针，它指向一个字符
重要：* 是跟着「变量名」的，不是跟着类型

下面两种写法完全等价，只是排版习惯不同：

int *p;      /* 常见写法 */
int* p;      /* 也合法，但容易误解 */

之所以提醒这点，是因为这一行有陷阱：

int *a, b;   /* 只有 a 是指针！b 是普通 int！ */

因为 * 只管它后面那一个变量。
想声明两个指针，要写 int *a, *b;， 或者干脆分行写清楚。

推荐的写法

把 * 紧贴变量名，并且一行只声明一个：

int *p;      /* 清晰 */
int *q;

这样不会看错，也符合「*p 是一个 int」的读法。

指针类型名：T*

先认识一个记号。假设有一个类型，名字叫 T，那么：

写法读作
T类型 T 本身
T*「指向类型 T 的指针」——它本身也是一个类型

把这个记号套进具体类型，就得到你已经见过的写法：

T 是什么T* 写成含义
intint*指向 int 的指针
doubledouble*指向 double 的指针
charchar*指向 char 的指针
要点：T* 是一个完整的类型

int* 不是「int 加个星号」，而是一个独立的类型名， 就像 double 一样是一个整体。

所以这样读最顺：「int* 是类型，p 是变量名」， 于是 int* p; 和 int x; 结构完全相同。

分清 * 的两种身份

初学者最容易混的就是这个：同一个 * 字符， 在类型名里和在表达式里完全是两回事。

出现在哪身份含义例子
类型名的一部分指针标记 说明「这是一个指针类型」int* p;
表达式里解引用运算符 顺着地址把值取出来*p = 10;
两个值中间乘号 乘法a * b

两个判断办法，哪个顺手用哪个：

看左边有没有类型名
像 int、double 这种类型关键字紧挨在左边 → 这是类型名的一部分
看能不能换成别的变量名
*p 里的 p 是已经存在的变量 → 这是解引用
对照：类型名 vs 解引用复制
int  x = 42;

/* 第 1 行：* 是【类型名的一部分】，声明 p 是一个 int* 类型的变量 */
int* p = &x;

/* 第 2 行：* 是【解引用运算符】，取出 p 指向的值 */
printf("%d\n", *p);      /* 42 */

/* 第 3 行：* 是【乘号】 */
printf("%d\n", x * 2);    /* 84 */
运行结果
42
84
一个简单的记忆法

看 * 左边的那个词是不是「类型」。

  • int* p —— 左边是 int，是类型 → 指针类型
  • *p = 10 —— 左边没有类型，p 是变量 → 解引用
  • x * 2 —— 两边都是值 → 乘法

另外提醒一句：同一行声明里出现的 * 都算类型名的一部分， 所以 int *a, b; 里的 * 只作用在 a 上 （前面那张警告卡片讲过）。

指针占多大

有意思的是：不管指向什么类型，指针自己占的字节数都一样。 因为它装的只是「房间号」，房间号的长度和房间里住什么无关。

指针的大小复制
#include <stdio.h>

int main(void) {
    int    a = 1;
    double d = 1.5;
    char   c = 'X';

    int    *pa = &a;
    double *pd = &d;
    char   *pc = &c;

    printf("sizeof(int*)    = %d\n", (int)sizeof(pa));
    printf("sizeof(double*) = %d\n", (int)sizeof(pd));
    printf("sizeof(char*)   = %d\n", (int)sizeof(pc));

    /* 但指向的内容大小完全不同 */
    printf("*pa = %d, *pd = %.1f, *pc = %c\n", *pa, *pd, *pc);
    return 0;
}
运行结果（64 位系统）
sizeof(int*)    = 8
sizeof(double*) = 8
sizeof(char*)   = 8
*pa = 1, *pd = 1.5, *pc = X

三个指针都是 8 字节（64 位系统上地址是 64 位）。 那既然大小一样，为什么还要区分 int* 和 double* 这两种类型？ 第 5 节的疑难 ② 会回答。

4& 与 * 是一对相反操作

这是理解指针最有用的一条规律：

★ 先取地址再解引用，等于什么都没做：*&x 就是 x。
就像「先问出房间号，再按房间号找过去」—— 你还站在原来的房间里。
验证 *&x == x复制
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;

    printf("x     = %d\n", x);
    printf("*&x   = %d   （先取地址再解引用，回到原值）\n", *&x);
    printf("*p    = %d\n", *p);
    printf("p == &x ? %d\n", p == &x);
    return 0;
}
运行结果
x     = 42
*&x   = 42   （先取地址再解引用，回到原值）
*p    = 42
p == &x ? 1

p == &x 输出 1（表示「成立」）， 说明 p 里装的确实就是 x 的地址，不是别的。

一张表看懂几个写法
写法是什么说明
x数值x 的值，如 42
&x地址x 的房间号
p地址和 &x 相同
*p数值和 x 相同，是「p 指向的值」
*&x数值就是 x

5疑难解答（十一问）

这一节把学指针时最常卡住的十一个问题逐个讲透。 如果你只读一节，就读这一节。

① 指针里到底装了什么？

疑惑：指针里装的是「值」还是「地址」？

装的是地址，一个数。而且它不是被指向变量的值。

看这段代码：

指针装的是地址复制
int x = 42;
int *p = &x;

printf("%d\n", x);     /* 42      —— x 里的值 */
printf("%p\n", (void *)p);   /* 一串地址 —— p 里的值 */

可以这样想：p 的「值」就是那个地址。 说「p 指向 x」是更形象的说法。

② 既然指针大小都一样，为什么还要分 int* / double*？

疑惑：都是 8 字节的地址，分类型岂不是多余？

因为类型决定了「到了那个房间之后，怎么读、读多少」。

同一个地址 0x1000：

  • 如果是 int*：从 0x1000 起读 4 字节，按整数解释
  • 如果是 double*：从 0x1000 起读 8 字节，按小数解释
  • 如果是 char*：从 0x1000 起读 1 字节，按字符解释

更关键的是「加 1」前进多少也要靠类型决定（见疑难 ⑦）。

所以类型必须匹配

int *p 只能指向 int。 让它指向 double，读出来的就是错的。

③ * 有三种含义，怎么区分？

疑惑：* 一会儿是「乘」，一会儿是「声明」，一会儿是「取值」，怎么分？

看 * 出现在哪里：

出现位置含义例子
两个数中间乘法a * b
类型和变量名之间
（声明语句里）		声明指针int *p;
变量名前面
（用在表达式里）		解引用取值*p = 10;

最需要分清的是后两种。看这两行：

声明 vs 取值复制
int *p = &x;    /* 这里的 * 是「声明 p 是指针」 */
*p = 99;        /* 这里的 * 是「取出 p 指向的格子，赋值为 99」 */

一个简单判断法：有类型名在前面的，就是声明；否则就是取值。

④ 没初始化的指针很危险

疑惑：int *p; 之后直接 *p = 5; 行不行？

绝对不行。这是指针最危险的错误。

int *p; 只是划出了一个装地址的格子，里面是垃圾值， 它指向一个随机的、可能根本不属于你的地方。 此时 *p = 5 等于往别人家里扔东西。

对比复制
int *p;        /* ❌ p 里是垃圾，不知道指向哪 */
*p = 5;       /* ❌ 危险！可能让程序崩溃 */

int x;
int *p = &x;  /* ✅ 声明时就指向一个真实的变量 */
*p = 5;       /* ✅ 安全，改的是 x */
安全习惯

指针要么声明时就赋一个真实地址，要么先赋 NULL。 不要留一个不知道指向哪的指针。

⑤ NULL 是干什么的？nullptr 又是什么？

疑惑：NULL 是什么？为什么老要判断它？

NULL 是一个特殊值，表示「这个指针不指向任何地方」， 相当于纸条上写「无」。

典型用法：函数找不到东西时返回 NULL， 调用方先判断再使用。

先判断，再使用复制
#include <stdio.h>

int main(void) {
    int *p = NULL;

    printf("p == NULL 吗？ %d\n", p == NULL);

    if (p == NULL) {
        printf("p 没指向任何地方，不能解引用\n");
    } else {
        printf("*p = %d\n", *p);
    }
    return 0;
}
运行结果
p == NULL 吗？ 1
p 没指向任何地方，不能解引用

*NULL 会导致程序崩溃，所以用之前一定要判断。

记法

NULL 之于指针，就像 0 之于数字 —— 一个表示「没有」的标记。

如果你以后写 C++：用 nullptr 更安全

我们这门课用的是 C 语言，写 NULL 就对了。 但你以后很可能会接触 C++ —— 那里从 C++11 起多了一个新写法 nullptr，用来表示「空指针」。

nullptr 比 NULL 更安全，原因是：

  • NULL 在 C++ 里通常就是数字 0， 所以它会「悄悄」变成整数，可能被当成数字参与运算或重载匹配，容易出错。
  • nullptr 有自己专门的类型，只表示空指针， 不会退化成整数，因此不会出现「本来想传指针，结果传了个 0」这类意外。
/* C   里这样写 */
int *p = NULL;

/* C++ 里推荐这样写 */
int *p = nullptr;

但本课程的所有代码都用 C，请继续写 NULL。 知道 nullptr 这回事、以及它更安全的原因就够了。

⑥ 数组的本质是什么？

疑惑：数组名 arr 到底是什么？为什么它和指针能混着用？

先把结论说清楚 —— 数组的本质是「一块连续的、同类型的内存」， 而数组名 arr 在绝大多数使用场合会自动变成「首元素的地址」。

第 1 层：数组就是一块连续的内存

这一点M03验证过。写 int arr[4]; 之后， 内存里出现 4 个紧挨着的 int 格子，共 16 字节：

int arr[4] —— 16 字节，4 个格子紧挨着（每个 4 字节）
arr[0]
10
+4 ─▶
arr[1]
20
+4 ─▶
arr[2]
30
+4 ─▶
arr[3]
40

因为是连续的，所以只要知道起点在哪、每格多宽， 就能算出任意一格的位置 —— 这正是「下标」能工作的原理。

第 2 层：数组名 = 首元素地址

把数组名单独拿出来用时，它表示第一个元素的地址：

数组名与首元素地址相同复制
#include <stdio.h>

int main(void) {
    int arr[4] = {10, 20, 30, 40};

    printf("arr      = %p\n", (void *)arr);
    printf("&arr[0]  = %p\n", (void *)&arr[0]);
    printf("两者相同吗？ %d\n", arr == &arr[0]);

    /* 既然数组名就是地址，那就能赋给指针 */
    int *p = arr;              /* 等价于 int *p = &arr[0]; */
    printf("*p = %d\n", *p);
    return 0;
}
运行结果
arr      = 000000000060FD7C
&arr[0]  = 000000000060FD7C
两者相同吗？ 1
*p = 10

这解释了一个你可能早就疑惑的写法： arr[i] 和 *(arr + i) 是一回事， 方括号只是「从首地址出发加偏移、再解引用」的简写。

E03 · 语法糖 把这一层拆得更细： arr[i] 与 arr[i][j] 本质上都是「先算地址、再取值」， 方括号只是编译器替你写好的糖。

两种写法完全等价复制
#include <stdio.h>

int main(void) {
    int arr[4] = {10, 20, 30, 40};

    for (int i = 0; i < 4; i++) {
        printf("arr[%d]=%d  *(arr+%d)=%d  相同吗？%d\n",
               i, arr[i], i, *(arr + i), arr[i] == *(arr + i));
    }
    return 0;
}
运行结果
arr[0]=10  *(arr+0)=10  相同吗？1
arr[1]=20  *(arr+1)=20  相同吗？1
arr[2]=30  *(arr+2)=30  相同吗？1
arr[3]=40  *(arr+3)=40  相同吗？1

第 3 层：但数组名不是「指针变量」

数组名虽然表现为地址，可它不是一个能改指向的指针变量：

对比复制
int arr[4];
int *p = arr;

p = arr + 2;      /* ✅ 指针变量可以改指向 */
arr = arr + 2;    /* ❌ 数组名不能改，编译不过 */

还有一个更实用的区别：数组名知道整个数组有多大，指针只知道一个地址。

sizeof 的差别复制
#include <stdio.h>

int main(void) {
    int arr[10];
    int *p = arr;

    printf("sizeof(arr) = %d   （整个数组：10 × 4）\n", (int)sizeof(arr));
    printf("sizeof(p)   = %d   （只是一个指针）\n", (int)sizeof(p));
    return 0;
}
运行结果（64 位系统）
sizeof(arr) = 40   （整个数组：10 × 4）
sizeof(p)   = 8   （只是一个指针）
三句话总结数组的本质
  1. 数组是一块连续的同类型内存，靠「首地址 + 下标 × 元素大小」定位每一格。
  2. 数组名在多数场合自动变成首元素地址，所以能赋给指针， arr[i] 等价于 *(arr + i)。
  3. 数组名不是指针变量：不能改指向，但 sizeof(arr) 能拿到整个数组的大小（而指针不行）。
这些知识马上要用到

第 3 点正是下一问的关键 —— 因为「数组名一进函数就退化成指针」， 所以函数里再也拿不到数组的真实大小，只能靠外面多传一个长度进来。

先把「退化」说清楚

上面第 2 层说「数组名会自动变成首元素的地址」。这件事有个正式说法，叫退化 —— 后面到处会遇到，所以这里讲准它。

一句话

数组名用在「需要指针」的位置时，编译器会自动把它换成一个 「指向第一个元素的指针」。

这个过程就叫退化（英文 decay）。从类型上看，是 int[4] 变成了 int*。

先岔一句：编译器是什么

上面反复说「编译器」。它就是把你写的源代码翻译成机器能执行的程序的那个工具 —— gcc、g++、cl.exe 都是它。

为什么这里要提它：「类型占多大」「地址怎么走」「数组名要不要退化」， 这些决定全是编译器做的，不是运行时的事。你在编辑器里写下的 int arr[4]，它得先算出「这占 16 字节、下一格在 4 字节后」， 才能把后面每一句翻译成正确的指令。

它具体做了哪几步、报错分别出在哪一步 —— F03 · 编译与链接、头文件与库 讲得最清楚 （第 3 节就叫「编译：各自翻译」）。本篇只用到其中一件事： 编译器会按类型规则改写你的表达式。

三个要点，把它和「类型转换」区分开：

要点意思
自动发生 你什么都不用写。只要把数组名放在一个需要指针的地方，编译器自己就换了 —— 所以你甚至感觉不到它发生过
只换「看法」，
不换数据		 内存里那 16 字节一个都没动，也不会另存一份指针。 变的只是编译器此刻怎么理解这个数组名
丢掉长度 退化之后只剩「从哪开始」，「有多长」没了 —— 下面那条「必须另传长度」的根源就在这里

它的痕迹很好认：上面第 3 层那个 sizeof(arr) = 40 与 sizeof(p) = 8，就是同一块内存被两种类型看出来的差别。 下一问会更直白 —— 同一个 sizeof(arr)，在 main 里是 40， 一进函数就变成 8。

附：为什么多维数组只有第一维可以省

写二维数组时有个常被问的问题：下面三种声明，为什么只有中间那个能过？

三种写法复制
int a1[2][3];   /* ✓ 合法 */
int a2[][3];    /* ✓ 合法：第一维省掉 */
int a3[2][];    /* ✗ 非法：第二维不能省 */

关键在于编译器要能算出一个元素占多大。

int[2][3] 可以理解成「2 个 int[3]」—— 它的一层元素是 int[3]，占 12 字节。所以：

a[i] 的地址 = 起始地址 + i × 12
—— 每跨一行，正好跳过 12 字节

这个「12」必须由第二维算出来。所以：

写法每行多大 行不行
int a[2][3]3 × 4 = 12 行 —— 两个都说了
int a[][3]3 × 4 = 12 行 —— 行宽有了，「几行」以后再补也行
int a[2][]算不出来 不行 —— 不知道一行多宽，a[1] 就找不到
一句话

第一维是「有几行」，第二维是「一行多宽」。

「几行」可以临时不知道 —— 有时能由初始化列表数出来； 但「一行多宽」必须知道，否则连第二行从哪开始都算不出来。

顺带一个推论：sizeof(int[2][3]) 是 24 （2 × 12）—— 和多维无关，仍然是「整个类型占多大」。

和「退化」连起来看

多维数组的类型里，每一维的大小都写着；而只要缺一维，编译器就没法算「下一行在哪」。

同一个道理：数组的类型里带着「每一维多大」，这是编译器算地址的依据。 省掉第一维还有救，省掉后面任何一维就断了这条依据。

⑦ 为什么数组传给函数时，还要额外传一个长度？

疑惑：函数参数写成 int a[]，为什么还要传 n？函数自己不能算出长度吗？

不能。这是学数组和函数时最常犯的疑惑，原因就在上一问的第 3 点。

先看现象

同一个 sizeof，两个地方结果不同复制
#include <stdio.h>

/* 函数里想自己算长度 */
int sizeInFunc(int arr[]) {
    return (int)sizeof(arr);
}

int main(void) {
    int arr[10];

    printf("main 里 sizeof(arr) = %d\n", (int)sizeof(arr));
    printf("函数里 sizeof(arr) = %d\n", sizeInFunc(arr));
    printf("sizeof(int*)       = %d\n", (int)sizeof(int *));
    return 0;
}
运行结果
main 里 sizeof(arr) = 40
函数里 sizeof(arr) = 8
sizeof(int*)       = 8

注意 函数里算出的是 8，正好等于 sizeof(int*)。 这说明：在函数眼里，arr 已经不是数组了，而是一个指针。

为什么？

因为把数组传给函数时，传进去的其实是首元素地址。 函数收到的是一个指针，它只知道「数据从哪儿开始」， 完全不知道「一共有多少个」。

调用 maxInArray(arr, 10) 时，函数实际拿到的东西
外面：arr（数组）
10 个格子
── 只传首地址 ──▶
函数里：int *arr
起点地址（不知多长）
＋
另外传的 n
10

所以函数里的「长度」只能靠外面告诉它。这就是那个 n 存在的唯一理由。

标准写法

数组 + 长度，成对出现复制
/* 只要看到数组参数，就习惯性地配一个 n */
int maxInArray(int a[], int n) {
    int mx = a[0];
    for (int i = 1; i < n; i++) {      /* 用 n，不能用 sizeof 算 */
        if (a[i] > mx) mx = a[i];
    }
    return mx;
}

/* 调用时把长度一起写上 */
maxInArray(arr, 10);

参数写成 int a[] 或 int *a 在功能上是一样的 （都表示「收到一个指向 int 的地址」），a[] 只是更能表达 「我期望你传一个数组来」这个意图。

一个常见的安全习惯

函数里既然不知道真实长度，就完全信任外面传进来的 n。 所以调用方有责任传对：传大了会越界，传小了会漏算。

另外，函数内部只用 a[i]（0 <= i < n）， 不要试图用 sizeof(a) 去算长度 —— 那一定是你以为的那个数。

「C 数组天生缺什么」这件事，M09 · vector 和 array 归成了三条短板（长度写死、不知道自己多长、不检查越界），可以对照着看。

⑧ 为什么指针「加 1」就是下一格？

疑惑：p + 1 是地址加 1 吗？

不是加 1 字节，而是「前进一个元素」。

前进多少字节由指向的类型决定： int* 前进 4 字节，char* 前进 1 字节，double* 前进 8 字节。

这正是疑难 ② 的答案 —— 指针类型的作用之一就是决定步长。

三种指针的步长复制
#include <stdio.h>

int main(void) {
    int    ia[2] = {0, 0};
    char   ca[2] = {0, 0};
    double da[2] = {0, 0};

    printf("int*    加 1 前进 %d 字节\n",
           (int)((char *)(&ia[0] + 1) - (char *)&ia[0]));
    printf("char*   加 1 前进 %d 字节\n",
           (int)((char *)(&ca[0] + 1) - (char *)&ca[0]));
    printf("double* 加 1 前进 %d 字节\n",
           (int)((char *)(&da[0] + 1) - (char *)&da[0]));
    return 0;
}
运行结果
int*    加 1 前进 4 字节
char*   加 1 前进 1 字节
double* 加 1 前进 8 字节

所以 p + 1 读作「下一个元素」， p + i 读作「往后数第 i 个元素」。 这个设计让指针遍历数组变得极其自然。

顺带一个常用技巧

两个指针相减，得到的是相隔几个元素（不是几字节）：

int *q = &arr[3];
int idx = (int)(q - arr);   /* 3 —— 正好是下标 */

⑨ 指针能不能改指向别的变量？

疑惑：指针指向一个变量后，还能改指向另一个吗？

能。指针变量本身也是变量，它的值（地址）可以重新赋值。 这和「通过指针改它指向的值」是两件不同的事，别搞混。

改指向 vs 改值复制
#include <stdio.h>

int main(void) {
    int u = 1, v = 2;
    int *p = &u;

    printf("一开始   *p = %d   （指向 u）\n", *p);

    *p = 100;                 /* ① 改【值】：u 变成 100 */
    printf("*p=100 后 u = %d, v = %d\n", u, v);

    p = &v;                     /* ② 改【指向】：p 现在指向 v */
    printf("改指向后 *p = %d   （指向 v）\n", *p);

    *p = 200;                 /* 这次改的是 v */
    printf("再 *p=200 后 u = %d, v = %d\n", u, v);
    return 0;
}
运行结果
一开始   *p = 1   （指向 u）
*p=100 后 u = 100, v = 2
改指向后 *p = 2   （指向 v）
再 *p=200 后 u = 100, v = 200

看最后一行：*p = 200 改的是 v， 因为此时 p 已经指向 v 了，u 保持在 100 不动。

两句话区分开
  • p = &v; → 改指向（换一张纸条）
  • *p = 200; → 改值（改房间里的东西）

⑩ *p++：先记住怎么用，不用深究

疑惑：看到 *p++ 这种写法就懵，是先取值还是先自增？

结论先摆出来，直接记住就行：

*p++ 读作：*(p++)
意思是 —— 先把 p 指向的那个值取出来用，然后 p 自己往后走一格。

容易搞混的其实只有两点，把这两点分清楚就够了。

第一点：顺序 —— 取值在前，自增在后

所以第一次 *p++ 取到的是第 0 个，不是第 1 个。 自增虽然写在后面，但它发生在「取值」之后。

第二点：对谁自增 —— 自增的是指针 p，不是它指向的值

这是最要紧的一点。用箭头想：p++ 是让箭头往后挪一格， 而箭头指着的那个格子里装的东西，一点没动。

执行 *p++ 的完整过程（假设 p 原本指向 arr[1]）
第 1 步：取值
取出 arr[1] 的值
然后 ──▶
第 2 步：自增
p 挪到 arr[2]
注意 ──▶
arr[1] 本身
原封不动
验证上面两点复制
#include <stdio.h>

int main(void) {
    int a[5] = {100, 200, 300, 400, 500};
    int *p = a;

    /* 逐个取出 *p++ */
    printf("依次取出  : ");
    for (int i = 0; i < 5; i++) {
        printf("%d ", *p++);
    }
    printf("\n");

    /* ① 自增的是 p：循环走了 5 次，p 就前进了 5 格 */
    printf("(p - a) = %d   （p 前进了 5 格）\n", (int)(p - a));

    /* ② 数组本身没被改动 */
    printf("数组内容  : %d %d %d %d %d\n",
           a[0], a[1], a[2], a[3], a[4]);

    /* ③ 取值在自增之前：第一次拿到的不是第 1 个 */
    int c[3] = {7, 8, 9};
    int *r = c;
    int first = *r++;
    printf("first = %d   （取到的是第 0 个）\n", first);
    printf("*r    = %d   （r 已经指向第 1 个）\n", *r);
    return 0;
}
运行结果
依次取出  : 100 200 300 400 500 
(p - a) = 5   （p 前进了 5 格）
数组内容  : 100 200 300 400 500
first = 7   （取到的是第 0 个）
*r    = 8   （r 已经指向第 1 个）

三行输出分别证明了：依次取出了全部 5 个值、 p 前进了 5 格（说明自增的是 p）、数组内容没变 （说明没动它指向的值）。

拆成两步，效果完全一样

如果 *p++ 让你觉得别扭，完全可以拆开写， 结果一模一样，而且更好读：

两种写法等价复制
/* 写法一：紧凑 */
for (int i = 0; i < n; i++) {
    printf("%d ", *p++);
}

/* 写法二：拆成两步（推荐初学者） */
for (int i = 0; i < n; i++) {
    printf("%d ", *p);   /* 先取值 */
    p++;                  /* 再让 p 前进一格 */
}
这一节只需要记住两句话
  1. *p++ 先取值，后自增 —— 所以第一次取到的是当前那一格。
  2. p++ 自增的是指针 p，不是它指向的值 —— 箭头往后挪，格子里东西不动。

至于别的花式写法，初学阶段不必去研究，容易把自己绕晕。 真遇到看不懂的写法，先按上面两句话拆解，或者干脆改写成两步。

⑪ 什么是指针的指针（二级指针）？

疑惑：int **pp; 两个星号是什么意思？

指针变量自己也有地址。把「指针的地址」存起来，就是二级指针。

用箭头想就清楚了：

两层箭头复制
int w = 5;
int *pw = &w;      /* pw  ──▶  w */
int **ppw = &pw;  /* ppw ──▶  pw ──▶  w */

*pw      /* 顺着 1 层箭头 → w 的值，即 5 */
**ppw    /* 顺着 2 层箭头 → w 的值，即 5 */
验证复制
#include <stdio.h>

int main(void) {
    int w = 5;
    int *pw = &w;
    int **ppw = &pw;

    printf("w     = %d\n", w);
    printf("*pw   = %d\n", *pw);
    printf("**ppw = %d\n", **ppw);
    printf("*ppw == pw ? %d\n", *ppw == pw);

    **ppw = 50;      /* 顺着两层箭头改，改的还是 w */
    printf("执行 **ppw = 50 后 w = %d\n", w);
    return 0;
}
运行结果
w     = 5
*pw   = 5
**ppw = 5
*ppw == pw ? 1
执行 **ppw = 50 后 w = 50
现在需要掌握到什么程度

能看懂 int **pp 是「两层箭头」就够了。 实际写代码时，二级指针用得不多（常见于需要修改「指针本身」的场合）。

初学阶段不必主动使用，遇到时知道它是什么就行。

6指针的强大之处

前面都在讲「是什么」。这一节讲「有什么用」—— 指针真正解决了哪些没有它就很难办的问题。

6.1 让函数修改外部变量

还记得M02的核心结论吗？普通变量传进函数的是「副本」， 函数里怎么改都不影响外面。

如果确实需要函数改外部变量呢？把地址传进去。

值传递传的是「值」，指针传的是「地址」
外面：x = 3
3
── 传 &x（地址）──▶
函数里：int *a
x 的地址

函数拿到地址后，就能顺着箭头回去改原来的变量：

经典 swap：交换两个变量复制
#include <stdio.h>

/* 参数写成指针：收的是地址 */
void swap(int *a, int *b) {
    int t = *a;      /* 取出 a 指向的值 */
    *a = *b;        /* 把 b 指向的值写进 a 指向的格子 */
    *b = t;
}

int main(void) {
    int x = 3, y = 8;

    printf("交换前 x=%d y=%d\n", x, y);
    swap(&x, &y);       /* 传的是地址，不是值 */
    printf("交换后 x=%d y=%d\n", x, y);
    return 0;
}
运行结果
交换前 x=3 y=8
交换后 x=8 y=3

对比一下两种写法，差别只在「传什么」：

写法函数里能否改外部变量调用方式
void f(int a)不能 改的是副本f(x);
void f(int *a)能 顺着地址回去改f(&x);
规律

想让函数改一个普通变量，就把它的地址 &x 传进去， 函数参数写成指针 int *a。

于是 scanf 那个 & 也解释通了： scanf 需要把读到的数写进你的变量， 所以它要的是地址 —— scanf("%d", &x)。

6.2 用指针遍历数组

因为指针「加 1 就是下一个元素」，用它遍历数组非常自然：

指针遍历复制
#include <stdio.h>

int main(void) {
    int a[5] = {100, 200, 300, 400, 500};

    /* 写法一：指针 + 下标（最易读） */
    int *p = a;
    for (int i = 0; i < 5; i++) {
        printf("%d ", p[i]);
    }
    printf("\n");

    /* 写法二：指针自己走，直到越过末尾 */
    for (int *r = a; r < a + 5; r++) {
        printf("%d ", *r);
    }
    printf("\n");

    /* 写法三：通过指针就地修改数组 */
    for (int *r = a; r < a + 5; r++) {
        *r = *r * 2;
    }
    for (int i = 0; i < 5; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");
    return 0;
}
运行结果
100 200 300 400 500 
100 200 300 400 500 
200 400 600 800 1000

三种写法都能用。初学阶段推荐写法一或写法二， 写法三用 *r 直接改数组内容，需要你对「解引用」已经很熟。

什么时候真的需要指针遍历

说实话，仅仅把数组走一遍的话，下标写法更清楚， 不必为了用指针而用指针。

指针遍历真正方便的地方是：当你只想处理数组中间的一段。 因为指针可以指向任意一格，所以 int *p = a + 2; 就能从第 3 个元素开始往后走，前面的元素完全不用管。

这个「从哪儿开始、走多少格」的搭配，正是疑难 ⑦ 「数组要额外传一个长度」里那个 n 的用法。

7常见错误

错误 1 · 用了没初始化的指针

对比复制
int *p;            /* ❌ 指向未知 */
*p = 5;           /* ❌ 危险，可能崩溃 */

int x;
int *p = &x;      /* ✅ 指向真实变量 */
*p = 5;           /* ✅ 改的是 x */

错误 2 · 把值和地址搞混

对比复制
int x = 42;
int *p = &x;

printf("%d\n", p);     /* ❌ 用 %d 打印地址，类型不对 */
printf("%p\n", (void *)p);  /* ✅ 地址用 %p */

int y = p;           /* ❌ 把地址赋给 int，语义混乱 */
int y = *p;          /* ✅ 要值就解引用 */

错误 3 · 忘记 &（swap 不生效）

对比复制
void swap(int *a, int *b) { ... }

swap(x, y);       /* ❌ 传的是值，编译就报错 */
swap(&x, &y);     /* ✅ 传地址 */

参数是 int *，就必须给地址。「参数带星，调用带与」。

错误 4 · 该解引用时没解引用

对比复制
void addOne(int *p) {
    p++;        /* ❌ 改的是「指针自己」（指向下一格） */
    *p += 1;    /* ✅ 改的是「指向的那个值」 */
}

错误 5 · 用 NULL 之前不判断

对比复制
int *p = find(a, n, x);

printf("%d\n", *p);          /* ❌ 如果没找到会崩溃 */

if (p != NULL) {              /* ✅ 先判断 */
    printf("%d\n", *p);
} else {
    printf("没找到\n");
}

错误 6 · int *a, b; 以为两个都是指针

对比复制
int *a, b;     /* ❌ b 是普通 int，不是指针 */
int *a, *b;    /* ✅ 两个都是指针 */

错误 7 · 拿指针当数组越界用

对比复制
int a[5];
int *p = a;

printf("%d\n", *(p + 5));   /* ❌ 越界！合法只有 p+0 ~ p+4 */
printf("%d\n", *(p + 4));   /* ✅ 最后一个 */

指针也不会替你检查边界，和数组一样要自己小心。

本讲要记住的七句话
  1. 指针就是一个变量，里面装的是别的变量的地址。
  2. & 取地址，* 顺着箭头取值；*&x 就是 x。
  3. T* 是一个完整类型名；同一个 *，在类型名里是「指针标记」， 在表达式里是「解引用」，两个值中间才是乘号。
  4. 指针必须初始化（指向真实变量或 NULL），绝不能用没初始化的指针。
  5. p = &v 是改指向；*p = 100 是改值。这是两件事。
  6. 数组名就是首元素地址，但数组名不是指针变量 —— 所以数组一进函数就退化，长度必须另外传一个 n。
  7. 想让函数改外部变量，就传地址 &x；参数写成 int *p。

  • 知道地址是什么，会用 & 和 *
  • 能读懂 void swap(int *a, int *b) 这类函数，并自己写出来
  • 理解为什么 scanf 要写 &x
  • 理解数组的本质，以及为什么数组参数总要配一个长度

再往后可以学的方向：动态内存（malloc / free）、 指针与结构体、函数指针。不过先把本讲这七个要点用熟，比急着往下学更重要。
