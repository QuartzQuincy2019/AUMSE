UME 项目组内部教程 · M09（Main） · C++ 标准库里的「数组」

C++ 本讲：更安全的数组

这一讲解决什么

M01学了数组，M05学了 malloc / free。 两者都能存一串数据，但都有麻烦：

  • 数组长度写死，运行时才知道要存几个就没办法
  • malloc 能解决长度问题，但要自己 free，忘一次就泄漏
  • 两者都不检查越界

C++ 标准库给了两个现成的替代品：vector 和 array。 实际项目里基本都用它们，很少直接用裸数组。

文中所有「运行结果」按 C++17 标准推演。

1裸数组的三个麻烦

先复习一下你已经在用的写法（「裸数组」= 语言自带的 int a[5]）：

裸数组复制
int raw[5] = {1, 2, 3, 4, 5};
cout << "sizeof = " << sizeof(raw) << endl;
运行结果
sizeof = 20
麻烦说明
① 长度写死 只能装 5 个。想装第 6 个？做不到 —— 数组一旦定义，大小就固定了。
② 不知道自己多长 一旦传进函数就「退化」成指针（M04），sizeof 失效， 必须额外传长度。
③ 不检查越界 raw[10] = 1; 编译器不报错，运行时悄悄改坏别的内存。

M05用 malloc 解决了①，但引入了新的麻烦： 得记住 free、得自己算字节数、还得判断 NULL。

这一讲的目标

把①②③一起解决掉，而且不用手动管理内存。

2vector：会自己长大的数组

std::vector 的核心能力是「能随时往里加东西，它自动扩容」。

会自己长大复制
#include <iostream>
#include <vector>            /* vector 在这里 */
using namespace std;

int main() {
    vector<int> v;                  /* 一开始是空的 */
    cout << "初始 size = " << v.size() << endl;

    for (int i = 1; i <= 5; i++) {
        v.push_back(i * 10);       /* 往末尾加一个 */
    }
    cout << "push_back 五次后 size = " << v.size() << endl;

    v.push_back(60);
    cout << "再 push 一个，size = " << v.size() << "，内容: ";
    for (int x : v) cout << x << " ";
    cout << endl;
    return 0;
}
运行结果
初始 size = 0
push_back 五次后 size = 5
再 push 一个，size = 6，内容: 10 20 30 40 50 60

注意三件事：

  • vector<int> 里的 <int> 是「装什么」： 想装小数就写 vector<double>， 想装字符串写 vector<string>。
  • 没有写长度 —— 一开始是空的，加多少它自己管。
  • 没有 free —— 变量离开作用域时自动释放（M06：析构函数）。
它把M05的麻烦包掉了
用 malloc 时你要做用 vector 时
malloc(sizeof(int) * n)vector<int> v; v.push_back(x);
算字节数不用
判断是不是 NULL不用
记住 free不用，自动
单独存一个长度变量 nv.size() 随时问

3常用操作

访问元素

[] 与 at 的区别复制
cout << "v[0] = " << v[0] << endl;        /* 和数组一样，不检查越界 */
cout << "v.at(0) = " << v.at(0) << endl;  /* 越界会抛异常（能抓到） */
cout << "front = " << v.front() << ", back = " << v.back() << endl;
运行结果
v[0] = 10, v[5] = 60
v.at(0) = 10
front = 10, back = 60
写法越界时什么时候用
v[i]不检查，未定义行为 确定下标合法时（循环里最常见）
v.at(i)抛异常，能捕获处理 下标来自用户输入 / 不确定时

三种遍历写法

都等价，习惯哪个用哪个复制
/* ① 下标：需要知道是第几个时用 */
for (size_t i = 0; i < v.size(); i++) cout << v[i] << " ";

/* ② 范围 for：最简洁，只要值 */
for (int x : v) cout << x << " ";

/* ③ 引用 + 范围 for：要修改元素时 */
for (int &x : v) x *= 2;          /* 注意那个 &，没有它就是改副本 */

/* ④ 迭代器：和标准库算法配合时用 */
for (vector<int>::iterator it = v.begin(); it != v.end(); ++it)
    cout << *it << " ";
运行结果
下标:   10 20 30 40 50 60 
范围for: 10 20 30 40 50 60 
迭代器: 10 20 30 40 50 60
范围 for 里的 & 很关键
for (int x : v)  { x *= 2; }   /* ❌ 改的是副本，v 没变 */
for (int &x : v) { x *= 2; }   /* ✅ 引用，改的是 v 里的元素 */

/* 只读遍历大对象时，加 const 避免拷贝（M07） */
for (const string &s : names) { cout << s; }

这正好是M07「引用」的实际用途 —— 想改就必须用引用。

加、插、删

插入与删除复制
vector<int> d{10, 20, 30, 40};

d.push_back(50);            /* 末尾加 */
d.pop_back();                /* 末尾删 */
d.insert(d.begin() + 1, 15);  /* 在下标 1 处插入 */
d.erase(d.begin() + 2);       /* 删掉下标 2 那个 */
d.clear();                   /* 全清空 */
运行结果
初始: 10 20 30 40 
在下标1前插15: 10 15 20 30 40 
删掉下标2: 10 15 30 40 
pop_back: 10 15 30 
clear 后 size = 0
头部/中间插入很慢

insert / erase 在中间或开头操作时， 后面所有元素都要往前或往后挪一格。

元素多的时候很慢。如果经常要在两头操作，用 deque； 经常要在中间插入，用 list。入门阶段记住「末尾 push_back 最快」就够了。

4size 与 capacity

这两个不一样，值得花一分钟搞清：

已使用（size = 3）    已预留但空着（capacity - size = 5）
回答的问题
v.size()装了几个元素
v.capacity()能装几个不用重新分配内存

为什么要有 capacity？因为扩容很贵： 内存里没有「原地长大」这回事，一旦满了，它得 找一块更大的地方、把老数据全搬过去、再释放老的。

reserve 预留容量复制
vector<int> c;
c.reserve(100);              /* 先把位置留好，避免反复搬家 */
cout << "capacity = " << c.capacity()
     << ", size = " << c.size() << endl;
运行结果
reserve(100) 后 capacity = 100, size = 0
什么时候该 reserve

如果你已经知道大概要装多少个（比如读文件前知道行数）， 先 reserve 一下能省掉多次搬家，明显更快。

不确定就不用管 —— 它会自己扩容，只是多搬几次家而已。先写对，再优化。

扩容会让你之前保存的指针/引用失效

扩容要搬家，所以扩容前拿到的元素地址，扩容后可能已经废了。 下面这种代码是危险的：

vector<int> v{1,2,3};
int *p = &v[0];        /* 拿到第一个元素的地址 */
v.push_back(4);
v.push_back(5);
v.push_back(6);            /* 这一步可能触发扩容搬家 */
*p = 99;                 /* ❌ p 可能已经指向已释放的老内存 */

规则：拿到元素的指针/引用后，不要再去 push_back。 要填数据就用下标 v[i]，每次现取。

5array：固定长度但更安全

如果长度本来就固定（比如「一个坐标就是 2 个数」）， 用 std::array 比裸数组好。

array：固定长度，但带 size()复制
#include <array>
using namespace std;

array<int, 5> ar = {5, 3, 8, 1, 9};

cout << "size() = " << ar.size() << endl;      /* 直接问长度 */
cout << "ar[0] = " << ar[0] << endl;
cout << "ar.at(4) = " << ar.at(4) << endl;   /* 越界抛异常 */
cout << "front = " << ar.front() << ", back = " << ar.back() << endl;
运行结果
内容: 5 3 8 1 9 
size() = 5
ar[0] = 5, ar.at(4) = 9
front = 5, back = 9

和裸数组的关键差别

大小一样，能力不同复制
int raw2[5] = {5, 3, 8, 1, 9};
array<int, 5> ar2 = {5, 3, 8, 1, 9};

cout << "sizeof(裸数组) = " << sizeof(raw2) << endl;
cout << "sizeof(array)  = " << sizeof(ar2) << endl;
cout << "array 能直接问长度: ar2.size() = " << ar2.size() << endl;

array<int, 5> ar3;
ar3 = ar2;                       /* 裸数组不能这样整体赋值 */
cout << "  ar3 = ar2 之后: ";
for (int x : ar3) cout << x << " ";
cout << endl;
运行结果
sizeof(裸数组) = 20  （20 字节）
sizeof(array)  = 20  （也是 20 字节）
array 能直接问长度: ar2.size() = 5
array 能整体赋值:
  ar3 = ar2 之后: 5 3 8 1 9
array 相比裸数组的三个好处
  1. 能问长度：ar.size()， 不需要再写 sizeof(a)/sizeof(a[0])。
  2. 能整体赋值：ar3 = ar2; 裸数组做不到。
  3. 能安全访问：ar.at(i) 越界会抛异常。

而大小和性能与裸数组完全一样（都是 20 字节，都在栈上，没有额外开销）。 所以没有理由再用裸数组。

传到函数里也方便

裸数组传参要额外传长度（M04的老问题）；array 不用：

/* 裸数组：长度得另外传 */
void printArr(int a[], int n);

/* array：长度写在类型里，函数里能自己问 */
void printArr(const array<int, 5> &a) {
    for (int x : a) cout << x << " ";
    cout << "（一共 " << a.size() << " 个）" << endl;
}

缺点是长度成了类型的一部分：array<int,5> 和 array<int,6> 是两个不同类型，函数不能通用。 这时候就该用 vector。

6三种怎么选

int a[5]
裸数组
长度固定，不知道自己的长度，不检查越界。

新代码里不要再用。
array<int,5>
固定长度，但更安全
能问长度、能整体赋值、能安全访问。
性能和裸数组一样。

长度真的固定时用它。
vector<int>
能自动增长
长度运行时定、不用管内存、能问长度。
比自己 malloc 安全得多。

不确定用哪个就用它。
情况选
长度编译时就知道，且不会变（坐标、矩阵维度） array<T, N>
长度运行时才知道（读文件、用户输入） vector<T>
会不断往里加东西vector<T>
要传给函数、长度不固定vector<T>（或 const 引用）
需要和只认裸数组的老式函数打交道 v.data() 取出裸指针
拿不定主意vector<T>
一句话原则

能固定就用 array，不确定就用 vector， 别再用裸数组和 malloc。

7配合标准库算法

vector / array 都能直接喂给标准库算法 （<algorithm>），排序、查找一行就够：

排序与查找复制
#include <algorithm>

vector<int> e{5, 3, 8, 1, 9, 2};

sort(e.begin(), e.end());                     /* 升序 */
sort(e.begin(), e.end(), greater<int>());   /* 降序 */

/* 查找：返回迭代器，找不到返回 end() */
auto it = find(e.begin(), e.end(), 8);
if (it != e.end())
    cout << "找到 8，下标 " << (it - e.begin()) << endl;
运行结果
排序前: 5 3 8 1 9 2 
排序后: 1 2 3 5 8 9 
降序:   9 8 5 3 2 1 
找到 8，下标 4
找 100: 没找到

注意 it - e.begin() —— 两个迭代器相减得到下标，和M04「两个指针相减」是同一个道理。

二维：vector 套 vector

3 行 4 列，全 0复制
vector<vector<int>> grid(3, vector<int>(4, 0));

for (int r = 0; r < 3; r++)
    for (int c = 0; c < 4; c++)
        grid[r][c] = r * 10 + c;

for (int r = 0; r < 3; r++) {
    for (int c = 0; c < 4; c++) cout << grid[r][c] << " ";
    cout << endl;
}
cout << "行数 = " << grid.size()
     << ", 列数 = " << grid[0].size() << endl;
运行结果
0 1 2 3 
10 11 12 13 
20 21 22 23 
行数 = 3, 列数 = 4

8和前面几讲的联系

讲的问题vector / array 怎么解决
M01数组长度写死、要自己记长度 push_back 自动增长，size() 随时问
M04数组传进函数就丢失长度 array 长度在类型里；vector 带 size()
M05malloc / free 要配对、要判空 全自动，析构时释放
M06「谁负责释放资源」 答案就是析构函数：vector 自己管自己
M07范围 for 里改元素要加 & for (int &x : v)
M08char* 的麻烦 改用 string 与 vector<string>
「资源交给对象管」这个思想

M06说「申请写在构造函数，释放写在析构函数」。 vector 就是这条原则的产物：

  • 它的构造函数里 malloc（或等价操作）
  • 它的析构函数里 free
  • 所以你什么都不用做

这个思想叫 RAII（资源获取即初始化），是 C++ 管理资源的核心套路。 以后你会看到 string、vector、智能指针都是同一个思路。

9常见错误

错误 1 · 越界访问不检查

对比复制
vector<int> v{1, 2, 3};

v[5] = 9;          /* ❌ 未定义行为，[] 不检查 */
v.at(5) = 9;       /* ✅ 抛异常，至少能发现 */

错误 2 · 用 <= 遍历

对比复制
for (size_t i = 0; i <= v.size(); i++)   /* ❌ 最后一次越界 */
for (size_t i = 0; i <  v.size(); i++)   /* ✅ */
for (int x : v)                            /* ✅ 最省心 */

错误 3 · 范围 for 里忘了 &

对比复制
for (int x : v)  { x *= 2; }   /* ❌ 改的是副本，v 没变 */
for (int &x : v) { x *= 2; }   /* ✅ */

错误 4 · 扩容后继续用老的指针/引用

对比复制
int *p = &v[0];
v.push_back(1);  v.push_back(2);  v.push_back(3);
*p = 99;                     /* ❌ p 可能已失效 */

v.push_back(1);  v.push_back(2);  v.push_back(3);
v[0] = 99;                  /* ✅ 每次现取下标 */

错误 5 · 把 vector 传参时不加引用

对比复制
void f(vector<int> v);              /* ❌ 每次调用都完整拷贝一份 */
void f(const vector<int> &v);      /* ✅ 只读，不拷贝 */
void f(vector<int> &v);              /* ✅ 要修改时用 */

这就是M07「大对象用 const 引用」的直接应用。 一个装了 10 万个元素的 vector，值传递会拷贝 10 万次。

错误 6 · vector<bool> 的小意外

知道有这回事就行复制
vector<bool> flags;      /* 合法，但内部按「位」压缩存储，
                            取出来的不是真正的 bool&，行为有点特殊 */
/* 入门阶段：要用布尔数组就用 vector<char> 或 deque<bool> 避开这个坑 */

本讲要记住的五句话
  1. vector 能自动增长、自动释放、自带长度 —— 取代「malloc + 手动长度」。
  2. array 和裸数组一样大、一样快，但能问长度、能整体赋值 —— 取代裸数组。
  3. size() 是装了几个，capacity() 是预留了几个； 扩容会搬家，所以别留着老的指针不放。
  4. 函数参数用 const vector<T>&，别值传递（会整个拷贝）。
  5. 范围 for 里要改元素就加 &，不加改的是副本。
