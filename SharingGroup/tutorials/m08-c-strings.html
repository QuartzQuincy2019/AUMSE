C 风格字符串

UME 项目组内部教程 · M08（Main） · 面向零编程基础成员

已学：数组 / 指针 / 内存 已学：作用域 本讲：一串文字怎么存

这一讲回答四个问题
  • M05里那个 malloc(sizeof(char) * (len + 1))， 为什么要 + 1？
  • 为什么字符串比较不能写 if (s1 == s2)？
  • 为什么 strcpy 老被说「不安全」？
  • sizeof 和 strlen 到底差在哪？

答案都在同一件事上：C 的字符串没有「字符串类型」， 它就是「一串字符 + 一个结束标记」。 文中所有「运行结果」均使用 g++ 13.1.0 以 C 风格实际编译运行核对。

1C 里的字符串长什么样

别的语言里有专门的字符串类型。C 里没有 —— C 用字符数组存一串文字，并在最后放一个特殊的字符表示「到此结束」。

C 字符串的完整定义

字符串 = 一串字符 + 结尾的一个 '\0'

'\0' 读作「空字符」，它的数值是 0 （不是字符 '0'，那个的数值是 48）。

写 char a[] = "Mongol"; 之后，内存里是这样：

M
a[0]
o
a[1]
n
a[2]
g
a[3]
o
a[4]
l
a[5]
\0
a[6]

「Mongol」是 6 个字符，但数组占 7 个格子 —— 最后那个格子专门放 '\0'。 这就是那个 + 1 的来历。

sizeof 比 strlen 多 1复制
#include <stdio.h>
#include <string.h>

int main(void) {
    char a[] = "Mongol";

    printf("内容: %s\n", a);
    printf("sizeof(a) = %d  （占多少字节）\n", (int)sizeof(a));
    printf("strlen(a) = %d  （几个字符）\n", (int)strlen(a));
    printf("差 %d —— 结尾多了一个 '\\0'\n",
           (int)(sizeof(a) - strlen(a)));
    return 0;
}
运行结果
内容: Mongol
sizeof(a) = 7  （占多少字节）
strlen(a) = 6  （几个字符）
差 1 —— 结尾多了一个 '\0'

逐字节看真实内容

把每个格子的数值打出来，'\0' 就现形了：

每个格子的数值复制
char a[] = "Mongol";
for (int i = 0; i < (int)sizeof(a); i++) {
    printf("a[%d] = %d\n", i, a[i]);
}
运行结果
a[0] = 77
a[1] = 111
a[2] = 110
a[3] = 103
a[4] = 111
a[5] = 108
a[6] = 0

最后那个 a[6] = 0 就是 '\0'。 （77、111 这些是字母的 ASCII 编码，第 6 节会讲。）

为什么要有结束标记

因为光看一块内存，没法知道字符串到哪里结束。

数组本身并不知道「我装了 6 个字符」—— 那个 7 是编译时写在程序里的。 而一个函数收到 char *s 时，它只知道起点， 必须一个字符一个字符往后走，直到遇到 0 才知道停了。

这也是 printf("%s", s) 的工作原理： 它靠 '\0' 判断什么时候停。 所以如果字符串忘了写 '\0'，printf 会一直往后读到越界为止 —— 这就是「乱码」甚至崩溃的来源。

2sizeof 与 strlen 的区别

这两个经常被混，但问的是完全不同的问题：

sizeof(a)
问：这块东西占多少字节？
编译时就算好了，运行时不做任何事。
只在「数组名」上有效 —— 用在指针上只会得到指针自己的大小。
包含 '\0'。
strlen(a)
问：从开头数到 '\0'，有几个字符？
运行时真的一格格数过去。
数组和指针都能用。
不包含 '\0'。
对数组和指针分别测试复制
char arr[] = "Mongol";
char *p = arr;              /* p 指向同一个字符串 */

printf("sizeof(arr) = %d\n", (int)sizeof(arr));
printf("sizeof(p)   = %d  （只是指针）\n", (int)sizeof(p));
printf("strlen(arr) = %d\n", (int)strlen(arr));
printf("strlen(p)   = %d\n", (int)strlen(p));
运行结果
sizeof(arr) = 7
sizeof(p)   = 8  （只是指针）
strlen(arr) = 6
strlen(p)   = 6

关键差别看第二行：sizeof(p) 是 8（指针大小）， 不是字符串的长度。这就是M04说过的「数组名不是指针变量」在字符串上的体现。

实用结论

算字符串长度一律用 strlen，不要用 sizeof。

sizeof 只在一种情况下用来算字符串相关的大小： 计算缓冲区需要多少字节，例如 char buf[sizeof(arr)];，或者
malloc(sizeof(char) * (strlen(src) + 1)) —— 注意那个 + 1。

3两种写法：数组 vs 指针

下面两种写法看起来很像，但含义不同：

两种写法的本质差别复制
char s1[] = "Mongol";      /* ① 数组：拷贝一份字符，可以改 */
char *s2  = "Mongol";      /* ② 指针：指向只读的字符串常量 */

s1[0] = 'T';                /* ✅ 可以改，s1 变成 "Tongol" */
/* s2[0] = 'T';   ← ❌ 不要这样写！那是只读内存，可能直接崩 */
写法它是什么能不能改内容
char s[] = "..." 一个数组，把字符拷进自己的格子 能改
char *s = "..." 一个指针，指向程序里只读的常量区 不能改 改了是未定义行为
运行结果
改过之后 s1 = Tongol
s2 = Mongol （不要改 s2[0]，那是只读区）
怎么选
  • 需要修改内容（拼接、替换、当缓冲区）→ 用数组， 或 malloc 出来的堆内存。
  • 只是读一读、当参数传 → 用 const char *， 明确表示「不会改」。

不确定时，const char * 最安全 —— 写成这样，编译器会替你拦住所有修改尝试。

4输入：scanf 与 fgets

读一串文字有两种常见方式，差别很大。

两种输入方式复制
char name[20];

/* ① scanf("%s", ...)：读到空格就停 */
scanf("%s", name);           /* 注意：不用写 & */

/* ② fgets：连空格一起读，且限制长度 */
fgets(name, sizeof(name), stdin);
scanf("%s", s)fgets(s, n, stdin)
遇到空格停 只读到第一个词 不停 整行都读进来
会不会越界会 输入太长就写爆数组 不会 有 n 兜着
换行符留在输入里会读进去（末尾多一个 \n）
要写 & 吗不用（数组名已经是地址）不用
为什么 scanf("%s", ...) 危险

它不知道你的数组有多大。用户输入 100 个字符，它就往 20 格的数组里写 100 个 —— 越界，程序可能崩，也可能被利用来做坏事。

想用 scanf 又限制长度，可以写宽度：

scanf("%19s", name);      /* 最多读 19 个，给 '\0' 留一格 */

但更省心的做法是直接用 fgets。

关于 scanf 里那个 &

回忆M04：scanf("%d", &x) 要写 &， 因为要告诉它「往哪个地址放」。

那为什么 scanf("%s", s) 不写？因为 数组名本身就是首元素的地址，已经是地址了，再加 & 就重复了。

这也解释了为什么 scanf("%d", &a[i]) 要写 —— a[i] 是一个元素（一个值），不是地址。

5常用函数一览

这些函数都在 <string.h> 里，用之前记得 #include <string.h>。

5.1 strlen：数长度

strlen复制
strlen("Mongol")         /* 6 */
strlen("")               /* 0 —— 空字符串也是合法字符串 */

它不包含结尾的 '\0'。空字符串 "" 占 1 个字节（只有 '\0'），长度是 0。

5.2 strcpy 与 strncpy：拷贝

拷贝：注意目标够不够大复制
char buf[32];
strcpy(buf, "Mongol");      /* 把 "Mongol" 连 '\0' 一起拷进 buf */
printf("%s\n", buf);        /* Mongol */
运行结果
strcpy 后: Mongol
strcpy 为什么不安全

它不检查目标缓冲区够不够大。如果源串比目标长，就会写越界。

它有个「限制长度」的版本 strncpy：

char small[6];
strncpy(small, "Mongolian", sizeof(small) - 1);   /* 最多拷 5 个 */
small[sizeof(small) - 1] = '\0';              /* 手动补上结束标记 */

实测结果：small = Mongo（被截断到 5 个字符）。

注意 strncpy 的一个坑：如果源串长度 ≥ 限制长度， 它不会自动补 '\0'。所以上面那行手动补结束标记不能省。

5.3 strcat：拼接

接在后面复制
char buf[32];
strcpy(buf, "Mongol");
strcat(buf, " bichig");     /* 找到 buf 末尾的 '\0'，从那里接着写 */
printf("%s\n", buf);
printf("长度 %d\n", (int)strlen(buf));
运行结果
strcat 后: Mongol bichig
长度 13

前提是 buf 一开始就是个合法的字符串（有 '\0'）， 否则 strcat 找不到该从哪里接。同样要注意别超出目标容量。

5.4 strcmp：比较的坑

这是最容易出错的一个。先看为什么不能写 ==：

== 比的是地址，不是内容复制
char x[] = "abc";
char y[] = "abc";
char *q = x;

printf("x == y  ? %d\n", x == y);              /* 两个不同的数组 */
printf("x == q  ? %d\n", x == q);              /* 同一个数组 */
printf("strcmp(x, y) = %d\n", strcmp(x, y));
运行结果
x == y  ? 0   （两个不同的数组，地址不同）
x == q  ? 1   （同一个数组）
strcmp(x, y) = 0  （0 表示内容相同）

x 和 y 内容都是 "abc"， 但 x == y 给出 0（不相等） —— 因为它比的是两个数组的地址，而它们当然是不同的数组。

strcmp 的返回值怎么读

它不是返回「是否相等」，而是返回「大小关系」：

返回值含义
0两个字符串完全相同
负数左边小于右边
正数左边大于右边
三种情况实测复制
printf("strcmp(abc,abd) = %d\n", strcmp("abc", "abd"));
printf("strcmp(abd,abc) = %d\n", strcmp("abd", "abc"));
printf("strcmp(abc,ab)  = %d\n", strcmp("abc", "ab"));
运行结果
strcmp(abc,abd) = -1
strcmp(abd,abc) = 1
strcmp(abc,ab)  = 1
正确用法
if (s1 == s2) { }              /* ❌ 比地址 */
if (strcmp(s1, s2) == 0) { }   /* ✅ 比内容 */
if (strcmp(s1, s2) != 0) { }   /* ✅ 不相等 */

不要写 if (strcmp(s1, s2)) 来表示「相等」—— 它把「相等」和「非零」搞反了，是极常见的错误。

为什么 strcmp 不直接返回「是 / 否」

因为它还要支持排序。有了「谁大谁小」这个信息， 就能直接拿来给字符串数组排序 —— 这也是它在设计上比「只返回是否相等」更有用的地方。

5.5 strchr：找一个字符

返回指向第一次出现位置的指针；找不到返回 NULL。

找空格并把后半段取出来复制
char text[] = "Mongol bichig";
char *found = strchr(text, ' ');

if (found != NULL) {
    printf("找到空格，位置是下标 %d\n", (int)(found - text));
    printf("空格之后的内容: %s\n", found + 1);
}

char *none = strchr(text, 'z');
printf("找 z：%s\n", none == NULL ? "没找到" : "找到了");
运行结果
找到空格，位置是下标 6
空格之后的内容: bichig
找 z：没找到

注意 found - text：两个指针相减，得到相隔几个字符（M04学过）。 这是「字符串里第几个位置」的标准算法。

6字符就是小整数

前面打印时出现过 a[0] = 77。为什么字符会变成数字？

因为char 本来就是一个小整数类型（M03讲过：占 1 字节， 能存 -128~127 或 0~255）。字符和数字之间只差一个「编码表」。

字符与数字的关系复制
printf("'A' = %d, 'a' = %d, 差 %d\n", 'A', 'a', 'a' - 'A');

char c = 'a';
printf("'a' 转大写: %c\n", c - 32);
printf("'a' - 'a' = %d\n", 'a' - 'a');
运行结果
'A' = 65, 'a' = 97, 差 32
'a' 转大写: A
'a' - 'a' = 0

由此能推出几个很有用的规律：

表达式作用
c >= '0' && c <= '9'判断是不是数字字符
c >= 'a' && c <= 'z'判断是不是小写字母
c - 'a'小写字母在字母表里的序号（a→0, b→1 …）
c - '0'把数字字符转成真正的数（'7'→7）
c - 32小写转大写（仅限英文）
只对英文字母成立

上面这些「减 32 变大写」「减 'a' 得序号」只适用于 ASCII 里的英文。

中文、蒙文、日文这些字符不是 1 个字节，也完全不符合这些规律 —— 它们要用「编码」来处理，那是第 09-F04 讲的内容。

不要把处理英文字符的办法套到非英文字符上。

7常见错误

错误 1 · 忘了给 '\0' 留位置

对比复制
/* ❌ 想放 6 个字符，却只给了 6 格 */
char s[6] = "Mongol";      /* 没有地方放 '\0' 了 */

/* ✅ 多给一格 */
char s[7] = "Mongol";      /* 6 个字符 + 1 个 '\0' */

/* ✅ 或者干脆不写长度，让编译器数 */
char s[] = "Mongol";       /* 自动是 7 */

动态分配时同理：malloc(sizeof(char) * (len + 1))， 那个 + 1 就是给 '\0' 的。

错误 2 · 用 == 比较字符串

对比复制
if (s1 == s2) { }              /* ❌ 比的是地址 */
if (strcmp(s1, s2) == 0) { }   /* ✅ 比内容 */

错误 3 · strcpy 目标太小

对比复制
char small[4];
strcpy(small, "Mongolian");    /* ❌ 写爆了 */

char small[10];
strncpy(small, "Mongolian", sizeof(small) - 1);
small[sizeof(small) - 1] = '\0';   /* ✅ 限制长度 + 补结束标记 */

错误 4 · 改字符串常量

对比复制
char *s = "Mongol";
s[0] = 'T';                  /* ❌ 只读内存，可能直接崩 */

char s[] = "Mongol";       /* ✅ 这是可改的数组 */
s[0] = 'T';

错误 5 · 用 sizeof 量字符串长度

对比复制
char *s = "Mongol";
int len = sizeof(s);           /* ❌ 得到 8（指针大小），不是 6 */
int len = strlen(s);           /* ✅ 得到 6 */

错误 6 · strncpy 之后忘了补 '\0'

对比复制
char small[6];
strncpy(small, "Mongolian", sizeof(small) - 1);
printf("%s\n", small);        /* ❌ 源串太长时没有 '\0'，会一直读到越界 */

strncpy(small, "Mongolian", sizeof(small) - 1);
small[sizeof(small) - 1] = '\0';   /* ✅ 手动补上 */
printf("%s\n", small);        /* ✅ Mongo */

8一页速查

想做的事写法
包含字符串函数#include <string.h>
声明可改的字符串char s[] = "Mongol";
声明只读的字符串const char *s = "Mongol";
留出 n 个字符的空间char s[n + 1];  /* +1 给 '\0' */
动态分配字符串空间malloc(sizeof(char) * (len + 1))
取长度strlen(s)
拷贝（目标够大时）strcpy(dst, src);
拷贝（限定长度）strncpy(dst, src, n - 1); dst[n-1] = '\0';
拼接strcat(dst, src);
比较内容是否相同strcmp(a, b) == 0
判断大小关系strcmp(a, b) < 0  /* a 在前 */
找字符char *p = strchr(s, ' ');
安全读入一整行fgets(buf, sizeof(buf), stdin);
判断字符类别c >= '0' && c <= '9'
数字字符转数值c - '0'
本讲要记住的五句话
  1. C 的字符串 = 一串字符 + 结尾的 '\0'， 所以放 n 个字符要 n+1 格。
  2. 算长度用 strlen，sizeof 只在数组名上才有「整体大小」的意思。
  3. 比较内容用 strcmp(a,b) == 0，== 比的是地址。
  4. strcpy / strcat 不检查目标容量， 目标不确定够大就用 strncpy 并手动补 '\0'。
  5. 字符就是小整数，差值有规律 —— 但那些规律只对英文字母成立。
