命令提示符（cmd）初步

UME 项目组内部教程 · F01（File） · 磁盘操作系统（DOS）的后代

Shell 不需要前置知识 本讲：在命令行里干活

为什么项目里要会这个

图形界面点几下就能做的事，命令行往往更快，而且能写进脚本自动化。

更重要的是：编译程序、看编译错误、运行带参数的程序， 这些事在命令行里做最直接。这一篇只讲最少必要的那一部分，很短。

所有命令都在 Windows 11 的 cmd 里实际验证过（cd 加引号、dir /b、chcp 65001）。其中 gcc 编译步骤使用 gcc 13.1.0 实际编译核对。

1它是什么、为什么要用

命令提示符（cmd）是一个黑底白字的窗口。你打字告诉它做什么， 它做完把结果打印出来。

它和 DOS 的关系

cmd 是 MS-DOS 的后代。DOS 是早期个人电脑的操作系统， 那时没有图形界面，一切操作都靠敲命令。

Windows 出来后，图形界面取代了日常操作，但命令行 保留了下来并且一直在用 —— 因为对某些任务它更高效。 cmd 的命令语法就是从 DOS 继承的。

还有更新的 PowerShell（更强）和 Windows Terminal（更好用的窗口）。 先把 cmd 学会，其余的都是它的超集。

图形界面命令行
双击打开文件夹cd 文件夹名
右键 → 复制 / 粘贴copy / move
看文件列表dir
双击 exe 运行程序名
把步骤记下来手动重复写成脚本，一键重跑
命令行真正的优势

不是「更快」，而是「可重复、可记录、可自动化」。

图形界面的操作留不下痕迹，下次还得重新点一遍； 命令行里你敲过什么清清楚楚，复制粘贴就能重来，还能存成 .bat 脚本让电脑自己跑。

2怎么打开

四种办法，按方便程度排：

Win + R
按 Win 键 + R，输入 cmd，回车。最快。
cmd
开始菜单
开始菜单搜「命令提示符」或 cmd。
地址栏
在资源管理器的地址栏里直接输入 cmd 回车 —— 会直接在当前文件夹打开，非常实用。
Shift + 右键
在文件夹空白处 Shift + 右键 → 「在此处打开 PowerShell 窗口」。
最省事的做法

资源管理器先进入你想要的文件夹，然后点地址栏、输入 cmd、回车。省掉后面 cd 找目录的麻烦。

3基本约定

打开后你会看到一行提示符：

命令提示符
Microsoft Windows [版本 10.0.19045.3803]
(c) Microsoft Corporation。保留所有权利。

C:\Users\Your_Username>_

C:\Users\Your_Username> 这个就叫提示符，它告诉你两件事：

  • 你现在在哪个目录（这里是 C:\Users\Your_Username）
  • 可以开始打字了（那条闪烁的横线是光标）
约定说明
回车执行打完命令按回车才生效
大小写不敏感DIR 和 dir 一样
↑ / ↓ 翻历史调出以前敲过的命令，非常常用
Tab 补全打一半按 Tab，自动补全文件名
Ctrl + C中断当前正在跑的命令
路径用反斜杠C:\Users\Your_Username（不是正斜杠）
右击即粘贴cmd 里 Ctrl+V 不一定灵，直接右键就粘贴
一个高频坑：路径里有空格

如果路径含空格（比如 C:\Program Files）， 必须用双引号包起来，否则 cmd 会以为空格后面是另一个参数：

空格的处理
C:\>cd C:\Program Files
系统找不到指定的路径。

C:\>cd "C:\Program Files"
C:\Program Files>

所以凡是路径，一律加引号最省心。

★4最该先会的几条命令

dir
列出当前目录里的文件。
dir dir *.cpp 只看 cpp 文件 dir /b 只列名字
cd
切换目录（change directory）。 cd .. 回上一级，cd \ 回根目录。
cd 项目\src cd .. cd \
cls
清屏，把窗口擦干净。
cls
type
把文本文件内容打印出来（相当于记事本只读）。
type readme.txt
mkdir / md
新建文件夹。
mkdir build
copy / move / del
复制、移动、删除文件。 del 删掉就进回收站之外了，小心。
copy a.txt b.txt move a.txt ..\bak\ del temp.txt
echo
打印一行字。写脚本时常用。
echo hello echo %PATH%
where
查一个程序装在哪 —— 排查环境问题特别好用。
where gcc where python

运行程序

直接敲程序名就行。如果程序在当前目录，要写 .\：

运行程序
C:\proj>hello.exe
'hello.exe' 不是内部或外部命令，也不是可运行的程序或批处理文件。

C:\proj>.\hello.exe
Hello
为什么要加 .\

出于安全考虑，cmd 默认不会在当前目录找程序， 只会在系统 PATH 环境变量列出的目录里找。

.\ 的意思是「当前目录」，加上它就等于告诉 cmd 「就在这儿，运行它」。

同理 ..\tool.exe 是「上一级目录里的 tool.exe」。

5一个完整流程

把上面的命令串起来：进到一个 C 源文件所在目录，编译它，再运行。

C:\Users\Your_Username>cmd
C:\Users\Your_Username>cd D:\Path\To\demo

D:\Path\To\demo>dir /b
main.c

D:\Path\To\demo>gcc -std=c99 main.c -o main.exe

D:\Path\To\demo>dir /b
main.c
main.exe

D:\Path\To\demo>.\main.exe
Hello, UME!

看一下每一步在做什么：

命令作用
cd D:\Path\To\demo切到源文件所在目录
dir /b确认文件在（/b 精简输出）
gcc -std=c99 main.c -o main.exe 编译；-o 指定输出的 exe 名字
.\main.exe运行刚编译出来的程序
编译有错时会怎样

错误信息会直接打印在窗口里，格式是 文件名:行号:错误说明。例如：

编译错误
D:\Path\To\demo>gcc -std=c99 main.c -o main.exe
main.c: In function 'int main()':
main.c:5:12: error: 'count' undeclared (first use in this function)
    5 |     printf("%d", count);
      |            ^~~~~

读法：打开 main.c，跳到第 5 行，第 12 列附近。 这就是为什么命令行编译比点按钮更好用 —— 错误定位信息完整、能复制、能搜索。

6常见问题

「不是内部或外部命令」怎么办

三种原因，按顺序排查：

原因解决办法
程序不在当前目录加 .\，或写完整路径
程序没装 / 名字拼错用 where 名字 查一下
装了但不在 PATH 里 写完整路径；或改用「开始菜单里那个专用命令行」 （比如 Qt 自带的，它会自动配好环境）

中文显示成乱码

cmd 默认用 GBK 编码。如果程序输出 UTF-8 就会乱码。可以临时切换：

切换编码
C:\>chcp 65001
Active code page: 65001
（65001 = UTF-8；想切回简体中文用 chcp 936）

编码这个话题在 T02《Unicode 和编码》里会专门讲。

想复制窗口里的内容

在窗口里用鼠标拖选，然后右键（或回车）就复制了。 不要用 Ctrl+C —— 那个是中断命令。

这一篇要记住的四件事
  1. cmd 是 DOS 的后代，用打字代替点鼠标，好处是可重复、可自动化。
  2. 最快打开方式：在资源管理器地址栏里输入 cmd。
  3. dir 看文件、cd 切目录、.\程序名 运行 —— 这三条覆盖大部分日常。
  4. 路径一律加引号，能省掉空格带来的麻烦。
