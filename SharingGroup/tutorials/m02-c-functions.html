C 本讲：函数

怎么用这份文档

和M01一样：先讲清楚，再给代码，代码后面紧跟运行结果。 代码框右上角有「复制」，鼠标移上去有反馈。

1为什么需要函数

先看一段「能跑但很难看」的代码。需求：判断 3 个数是不是素数。

没有函数：同样的判断写了三遍复制
#include <stdio.h>

int main(void) {
    int a = 7, b = 12, c = 13;

    /* 判断 a */
    int ok1 = 1;
    if (a < 2) ok1 = 0;
    for (int i = 2; i * i <= a; i++) {
        if (a % i == 0) { ok1 = 0; break; }
    }

    /* 判断 b —— 又抄一遍 */
    int ok2 = 1;
    if (b < 2) ok2 = 0;
    for (int i = 2; i * i <= b; i++) {
        if (b % i == 0) { ok2 = 0; break; }
    }

    /* 判断 c —— 再抄一遍 */
    int ok3 = 1;
    if (c < 2) ok3 = 0;
    for (int i = 2; i * i <= c; i++) {
        if (c % i == 0) { ok3 = 0; break; }
    }

    printf("%d %d %d\n", ok1, ok2, ok3);
    return 0;
}
运行结果
1 0 1

代码是能跑的，但有三个问题，而且会随着需求变大越来越严重：

重复
同一段判断抄了三遍，写 100 个数就要抄 100 遍
难改
发现判断逻辑写错了，得改 3 个地方
难读
main 里塞满了细节，看不出整体在做什么

用函数改写之后：

有函数：判断逻辑只写一遍复制
#include <stdio.h>

/* 把「判断素数」打包成一个名字 */
int isPrime(int n) {
    if (n < 2) {
        return 0;
    }
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return 0;
        }
    }
    return 1;
}

int main(void) {
    int a = 7, b = 12, c = 13;
    printf("%d %d %d\n", isPrime(a), isPrime(b), isPrime(c));
    return 0;
}
运行结果（完全一样）
1 0 1

判断逻辑只写了一遍，main 也从十几行缩到三行。 要判断 100 个数，只是多调用几次 isPrime 而已。

函数的本质

函数 = 把一段代码打包起来，起个名字，以后用名字来使用它。

好处正好对应上面的三个问题：不用抄、改一处就够、main 变得清爽。

你其实早就在用函数了

printf、scanf 就是别人写好的函数，放在 stdio.h 里。你写 printf("...") 的时候， 就是在调用一个函数 —— 只不过它是别人写的。

本讲要做的事，就是学会写自己的函数。

2函数长什么样

先看一个完整的函数，再逐块拆开：

一个完整的函数复制
int add(int a, int b) {
    int s = a + b;
    return s;
}
int 返回值类型 add 函数名 (int a, int b) 参数表 { ... } 函数体
返回值类型 — 这个函数「算出来的东西」是什么类型 函数名 — 你给它起的名字，以后靠这个名字叫它 参数表 — 它需要你提供哪些材料 函数体 — 具体怎么算

用一句话概括这个结构：

返回值类型  函数名 （材料清单） { 怎么算 }
读作：「给我这些材料，我还你一个什么东西。」

对比你已经会的东西

你熟悉的 main自己写的函数
int main(void) { ... }int add(int a, int b) { ... }
返回值类型是 int返回值类型是 int
名字必须叫 main名字自己起（add）
参数是 void，表示不要材料参数是 int a, int b，要两个整数
整个程序的起点被调用的工具

看出来了吗？main 本身也是一个函数， 只是它很特殊 —— 程序从它开始执行，而且没人调用它（是系统替你调用的）。

三种常见形态

有形参有返回 / 有形参无返回 / 都没有复制
/* ① 要材料，也要还东西 */
int square(int x) {
    return x * x;
}

/* ② 要材料，但不还东西（只是做点事，比如打印） */
void greet(char who[]) {
    printf("Hello, %s!\n", who);
}

/* ③ 不要材料，也不还东西 */
void sayHello(void) {
    printf("Hello, C!\n");
}
void 的两个位置，意思不同
  • 写在最前面（返回值类型）：void greet(...) —— 这个函数不还东西，所以调用它时不能写 int x = greet(...);
  • 写在括号里（参数表）：void sayHello(void) —— 这个函数不要材料，调用时写 sayHello()，括号里空着

3定义与调用

函数要发挥作用，需要两步：

① 定义
把「怎么算」写出来，告诉编译器有这么个工具
② 调用
在需要的地方写上名字，让它干活
定义 + 调用复制
#include <stdio.h>

/* ① 定义：把做法写清楚 */
int square(int x) {
    return x * x;
}

int main(void) {
    /* ② 调用：写名字，括号里给材料 */
    int r = square(5);      /* 把 5 交给 square，拿回结果存进 r */
    printf("r = %d\n", r);

    /* 也可以直接用在表达式里 */
    printf("3*3 + 4*4 = %d\n", square(3) + square(4));

    /* 还能套着用：先算 square(2)=4，再算 square(4)=16 */
    printf("square(square(2)) = %d\n", square(square(2)));
    return 0;
}
运行结果
r = 25
3*3 + 4*4 = 25
square(square(2)) = 16

调用时可以给具体的数，也可以给变量、表达式：

调用时的三种材料复制
int n = 6;
square(5);          /* 直接给数 */
square(n);          /* 给变量 */
square(n + 1);      /* 给表达式，会先算出 7 再传进去 */
square(square(2));  /* 把上一个结果当材料 */
「定义」和「调用」的写法差别
定义时调用时
要不要写类型要：int x不要：只写值
有没有函数体有 { }没有，只有名字和括号
例子int square(int x) { ... }square(5)

4返回值

return 做两件事：把结果交出去，同时立刻结束这个函数。

返回值类型要对得上

返回不同类型复制
int add(int a, int b) {
    return a + b;          /* 返回整数 */
}

double average(int sum, int n) {
    return (double)sum / n;  /* 返回小数 */
}

int isEven(int n) {
    return n % 2 == 0;      /* 返回 1 或 0，当「是/否」用 */
}
用 0 / 1 表示「否 / 是」是常见习惯

C 语言里没有真正的「真/假」类型（初学阶段这样理解就好）， 大家约定：返回 0 表示否，返回非 0（通常写 1）表示是。

所以判断语句可以直接写 if (isPrime(n))， 意思是「如果 isPrime(n) 返回的不是 0」。
反过来写 if (isPrime(n) == 0) 就是「如果返回 0，即不是素数」。

return 会立刻结束函数

这是 return 很重要的性质，可以用来简化代码：

用 return 提前退出复制
/* 写法一：用标志变量 */
int isPrime1(int n) {
    int ok = 1;
    if (n < 2) ok = 0;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) { ok = 0; break; }
    }
    return ok;
}

/* 写法二：直接 return，更清楚 */
int isPrime2(int n) {
    if (n < 2) {
        return 0;              /* 立刻结束，后面的代码不会执行 */
    }
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return 0;          /* 找到一个因子就够，不用再找 */
        }
    }
    return 1;                  /* 一路都没被 return 掉，说明是素数 */
}

写法二不需要 ok 这个变量，也不用 break， 读起来就是「遇到什么情况就返回什么」，更贴近人的思路。

没有返回值的函数

void 函数复制
void printLine(int n) {
    for (int i = 0; i < n; i++) {
        printf("-");
    }
    printf("\n");
    /* 没有 return，或者写 return; （不带值）都可以 */
}
两个容易犯的错
  • 该返回却没返回。如果函数声明是 int， 但某条路径走下来没有 return，结果就是不确定的。 编译器可能只给个警告，程序照样跑 —— 这种 bug 很难查。
  • 把 void 函数的返回值拿来用。 int x = printLine(5); 是错的，因为它不还东西。

5参数

参数就是函数需要的「材料清单」。定义时写类型和名字，调用时只给值。

几个参数都行

0 个、1 个、2 个、3 个参数复制
void sayHello(void) { ... }                       /* 0 个 */
int  square(int x) { ... }                       /* 1 个 */
int  add(int a, int b) { ... }                  /* 2 个 */
int  max3(int a, int b, int c) { ... }         /* 3 个 */

形参和实参

这两个词听起来吓人，其实就是「定义时的名字」和「调用时给的值」：

叫法出现在哪例子
形参函数定义的括号里 int add(int a, int b) 里的 a 和 b
实参函数调用的括号里 add(3, 4) 里的 3 和 4

形参的名字随便起，但顺序和类型要和实参对得上：

顺序错了，结果就错了复制
int sub(int a, int b) {
    return a - b;
}

sub(10, 3);   /* ✅ a=10, b=3  结果 7  */
sub(3, 10);   /* ❌ 顺序反了  结果 -7 */
运行结果
7
-7
起名的建议

形参的名字尽量有意义。下面两版功能一样，但第二版一看就懂：

  • int f(int a, int b) { return a * b; } —— 得猜 a、b 是什么
  • int area(int w, int h) { return w * h; } —— 一眼看出是宽乘高

6值传递（本讲最重要的一节）

这是学函数时最容易误解的一点，请慢慢看。

核心结论

调用函数时，传给形参的是实参的一份「副本」。

也就是说：函数里拿到的是一个拷贝， 它在函数里怎么改，都不会影响外面的原变量。

画个图理解。执行 square(n) 时，发生了这样的事：

main 里的 n（原变量）
n = 10
── 复制一份 ──▶
square 里的 x（副本）
x = 10

square 里无论把 x 改成什么， 改的都是右边这个副本，左边的 n 一动也不动。

动手验证：函数里改了，外面没变复制
#include <stdio.h>

void tryChange(int x) {
    printf("  函数里，改之前 x = %d\n", x);
    x = 999;                              /* 改的是副本 */
    printf("  函数里，改之后 x = %d\n", x);
}

int main(void) {
    int n = 10;
    printf("调用前，n = %d\n", n);

    tryChange(n);

    printf("调用后，n = %d\n", n);   /* 还是 10！ */
    return 0;
}
运行结果
调用前，n = 10
  函数里，改之前 x = 10
  函数里，改之后 x = 999
调用后，n = 10

函数里明明把 x 改成了 999，回到 main， n 还是 10。这就是值传递。

记住这个比喻：你把文件复印一份交给同事， 他在复印件上怎么涂改，你手里的原件都不会变。
值传递传的就是「复印件」。

那函数怎么把结果送出来？

用 return。函数想给外面的东西，只能通过返回值送出去。

正确做法：靠返回值复制
#include <stdio.h>

/* 想要「把 n 变成两倍」，不能改形参，而要 return 新值 */
int doubled(int x) {
    return x * 2;
}

int main(void) {
    int n = 10;

    /* 在外面用返回值更新自己，这才改得动 */
    n = doubled(n);
    printf("n = %d\n", n);
    return 0;
}
运行结果
n = 20

关键在这一句：n = doubled(n);

doubled(n)
把 10 的副本传进去，算出 20 并返回
n = 20
在 main 里把返回值赋给 n，这才是真的改了 n
值传递的好处

换个角度想：因为函数拿到的是副本，所以你不用担心调用一个函数会把变量弄坏。 square(n) 无论内部怎么折腾，你的 n 都是安全的。 这让函数用起来很放心。

数组作为参数时的情况

有一点要提前说明：把数组传给函数时，行为与普通变量不同 —— 函数里对数组元素的修改会影响原数组。

这一点第 9 节会专门演示。现在先记住： 普通变量是「复印件」，数组是「同一本」。

7变量的作用范围

在函数里定义的变量，只在这个函数里活着。出了这个函数就没了。

各管各家复制
#include <stdio.h>

void f(void) {
    int a = 100;      /* 这个 a 只属于 f */
    printf("f 里的 a = %d\n", a);
}

int main(void) {
    int a = 1;        /* 这个 a 只属于 main，和上面的 a 毫无关系 */
    printf("main 里的 a = %d\n", a);
    f();
    printf("调用 f 之后，main 里的 a 还是 %d\n", a);
    return 0;
}
运行结果
main 里的 a = 1
f 里的 a = 100
调用 f 之后，main 里的 a 还是 1

两个 a 名字一样，但是两个完全无关的变量， 各在各的函数里，互不干扰。

形参也是这个函数的「内部变量」

形参 x 只在这个函数里存在。别的函数里也可以叫 x，不冲突。

两个函数都用 x，互不影响复制
int inc(int x) {
    return x + 1;
}

int dec(int x) {
    return x - 1;
}
循环里定义的变量也一样

你在M01见过的这种写法：

for (int i = 0; i < n; i++) {
    int t = i * 10;    /* t 只在这个 for 里活着 */
}

出了这个 for，i 和 t 就都不存在了， 不能再使用。

8先声明后使用

C 语言有个规矩：函数必须先「见过」，才能调用。 所以定义要写在调用它的地方前面。

问题：互相调用怎么办

如果 f 想调用 g，g 又想调用 f， 无论谁写前面都不对 —— 总有一个「还没见过」。

解决办法是函数声明（也叫函数原型）：只写函数头，加个分号，不写函数体。

先声明，后定义复制
#include <stdio.h>

/* ① 声明：告诉编译器「有这么个函数」，先不写怎么做 */
int cube(int x);

int main(void) {
    /* ② 这里就能用了，虽然 cube 的真正定义还在下面 */
    printf("cube(3) = %d\n", cube(3));
    return 0;
}

/* ③ 定义：现在才写怎么做 */
int cube(int x) {
    return x * x * x;
}
运行结果
cube(3) = 27

声明和定义的区别，就看有没有函数体：

写法作用
声明int cube(int x);告诉编译器「有这个东西」
定义int cube(int x) { ... }真正写出怎么做
写代码的建议顺序

养成这个习惯，就不用老想着「谁该写前面」：

  1. 开头把要用的函数声明一遍
  2. 然后是 main
  3. 最后统一写各个函数的定义

这样 main 放在靠前的位置，读代码的人一眼就能看到整体流程。

9函数配数组

函数和数组配在一起特别好用。因为数组常常需要「同一类处理」， 比如求最大、求和、查找 —— 这些都可以做成函数，反复使用。

数组作为参数怎么写

方括号里留空，长度另外传复制
int maxInArray(int a[], int n) {
    /*            ↑ 方括号留空      ↑ 长度单独作为参数传进来 */
    int mx = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > mx) {
            mx = a[i];
        }
    }
    return mx;
}
为什么长度要单独传

因为函数没法从 a[] 看出数组有多长。 所以必须额外给一个 n，明确告诉它「只看前 n 个」。

调用时把长度一起写上：maxInArray(a, 6)。

完整例子

求最大 / 求和 / 求平均复制
#include <stdio.h>

int maxInArray(int a[], int n) {
    int mx = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > mx) mx = a[i];
    }
    return mx;
}

int sumOfArray(int a[], int n) {
    int s = 0;
    for (int i = 0; i < n; i++) {
        s += a[i];
    }
    return s;
}

int main(void) {
    int a[6] = {88, 92, 79, 95, 61, 84};

    printf("max = %d\n", maxInArray(a, 6));
    printf("sum = %d\n", sumOfArray(a, 6));
    printf("avg = %.2f\n", sumOfArray(a, 6) / 6.0);
    return 0;
}
运行结果
max = 95
sum = 499
avg = 83.17

注意 maxInArray(a, 6) 里的 a 写法： 只写数组名，不写方括号。写成 a[] 或 a[6] 都不对。

重要差别：函数里改了数组，外面真的会变

第 6 节说过，普通变量传的是「复印件」。但数组不一样，我们验证一下：

函数里改数组 vs 改普通变量复制
#include <stdio.h>

void changeVar(int x) {
    x = 999;                /* 改副本 */
}

void changeArray(int a[], int n) {
    /* 把每个元素都乘 2 */
    for (int i = 0; i < n; i++) {
        a[i] = a[i] * 2;
    }
}

int main(void) {
    int v = 10;
    int a[3] = {1, 2, 3};
    int n = 3;

    changeVar(v);
    printf("普通变量 v = %d    （没变）\n", v);

    changeArray(a, n);
    printf("数组     a = %d %d %d  （变了！）\n", a[0], a[1], a[2]);
    return 0;
}
运行结果
普通变量 v = 10    （没变）
数组     a = 2 4 6  （变了！）
这两条要一起记住
传给函数的东西函数里改了会怎样
普通变量（int、double…）外面不受影响（改的是副本）
数组外面会跟着变（操作的是同一批格子）

所以：想通过函数「改掉一个普通变量」，就用返回值； 想通过函数「改掉一个数组的内容」，直接改元素就行，不用返回。

这个特性很有用

比如写一个「把数组所有元素加 1」的函数，就不需要返回值了：

void addOneToAll(int a[], int n) {
    for (int i = 0; i < n; i++) {
        a[i]++;
    }
}

调用完，原数组就已经被改好了。

10把大问题拆成小函数

函数最实际的用处，是把一个大问题拆成几个小问题，每个小问题写一个函数。 这样每一步都很简单，合起来就把难题解决了。

举例：输入 6 个成绩，输出最高分、平均分、及格人数。

先想清楚要哪几个「小工具」：

最高分
maxInArray(a, n)
平均分
sumOfArray(a, n) / n
及格人数
countAtLeast(a, n, 60)
三个小函数 + 一个清爽的 main复制
#include <stdio.h>

int maxInArray(int a[], int n) {
    int mx = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > mx) mx = a[i];
    }
    return mx;
}

int sumOfArray(int a[], int n) {
    int s = 0;
    for (int i = 0; i < n; i++) {
        s += a[i];
    }
    return s;
}

/* 数出 >= line 的个数 */
int countAtLeast(int a[], int n, int line) {
    int c = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] >= line) c++;
    }
    return c;
}

int main(void) {
    int a[6] = {88, 52, 79, 95, 61, 84};
    int n = 6;

    printf("最高分：  %d\n", maxInArray(a, n));
    printf("平均分：  %.2f\n", sumOfArray(a, n) / (double)n);
    printf("及格人数：%d\n", countAtLeast(a, n, 60));
    printf("90 分以上：%d\n", countAtLeast(a, n, 90));

    return 0;
}
运行结果
最高分：  95
平均分：  76.50
及格人数：5
90 分以上：1

注意 countAtLeast 被用了两次，只是分数线不同 —— 一个函数，两处复用，这就是函数的价值。

看 main 的最后几行 —— 读起来就像在读题目本身， 不需要再去看循环细节。这就是拆函数最大的好处。

拆函数的思路

拿到一道题，先别急着写 for。先问自己：

  1. 这道题要算哪几件事？（比如：最高分、平均分、人数）
  2. 每件事能不能用一个函数完成？给它起个一看就懂的名字。
  3. 每个函数只管一件事，写起来就简单了。
  4. 最后在 main 里把它们串起来。

再练一个：判断回文数

「回文数」指正着读和倒着读一样，比如 12321。拆成两个小函数：

先写「反转整数」，再用它判断回文复制
#include <stdio.h>

/* 小工具一：把一个整数的数字倒过来 */
int reverseInt(int n) {
    int r = 0;
    while (n > 0) {
        r = r * 10 + n % 10;
        n /= 10;
    }
    return r;
}

/* 小工具二：判断是不是回文（直接用工具一） */
int isPalindrome(int n) {
    return n == reverseInt(n);
}

int main(void) {
    printf("reverse(1234) = %d\n", reverseInt(1234));
    printf("12321 是回文吗？%d\n", isPalindrome(12321));
    printf("1234  是回文吗？%d\n", isPalindrome(1234));
    return 0;
}
运行结果
reverse(1234) = 4321
12321 是回文吗？1
1234  是回文吗？0

注意 isPalindrome 有多短 —— 因为它站在 reverseInt 的肩膀上。 函数可以相互调用，一个小工具可以建立在另一个小工具之上。

配合循环使用

函数一旦写好，配合循环就能反复使用，这是它最省事的地方：

打印 1~20 里的素数复制
for (int v = 1; v <= 20; v++) {
    if (isPrime(v)) {
        printf("%d ", v);
    }
}
运行结果
2 3 5 7 11 13 17 19

如果判断素数的逻辑改了，只要改 isPrime 一处， 所有调用它的地方都会跟着变正确 —— 这就是第 1 节说的「改一处就够了」。

11常见错误

错误 1 · 调用时多写了类型

对比复制
int square(int x) { return x * x; }

square(int 5);   /* ❌ 调用时不要写类型 */
square(5);       /* ✅ */

类型只在定义时写一次。调用时只给值。

错误 2 · 忘了接收返回值

对比复制
int n = 10;

doubled(n);        /* ❌ 算完就丢了，n 一点没变 */
n = doubled(n);    /* ✅ 把返回值存回去 */

这是第 6 节值传递的直接后果：返回值不用，就等于没算。

错误 3 · 以为改形参能改外面

对比复制
/* ❌ 想让外面的 n 变成 2 倍，但改的是副本 */
void bad(int x) { x = x * 2; }

/* ✅ 用 return 把结果送出来 */
int good(int x) { return x * 2; }

错误 4 · 数组名后面多写了方括号

对比复制
int a[6] = {88, 92, 79, 95, 61, 84};

maxInArray(a[], 6);   /* ❌ */
maxInArray(a[6], 6);  /* ❌ 而且还越界了 */
maxInArray(a, 6);     /* ✅ 只写数组名 */

错误 5 · int 函数没有在所有路径上 return

对比复制
/* ❌ n 为负数时没有 return，结果不确定 */
int bad(int n) {
    if (n > 0) {
        return 1;
    }
}

/* ✅ 保证每条路都有 return */
int good(int n) {
    if (n > 0) {
        return 1;
    }
    return 0;      /* 兜底 */
}

错误 6 · 定义写在调用之后，又没声明

对比复制
/* ❌ main 在 cube 之前，编译器没见过 cube */
int main(void) {
    printf("%d\n", cube(3));
    return 0;
}
int cube(int x) { return x * x * x; }

/* ✅ 在 main 之前加一行声明 */
int cube(int x);
int main(void) { ... }

12一页速查

想做的事写法
定义无参无返回void f(void) { ... }
定义有参有返回int f(int a, int b) { ... return r; }
定义有参无返回void f(int a) { ... }
返回小数double f(int a) { return (double)a / 2; }
返回「是 / 否」return 1; / return 0;
提前结束函数return;
调用f(3, 4);
用返回值int r = f(3, 4);
先声明后使用int f(int a, int b);
数组作参数int f(int a[], int n)
调用数组参数f(a, n);
通过函数改普通变量n = f(n);  （靠返回值）
通过函数改数组内容直接改 a[i]，不用返回
本讲要记住的五句话
  1. 函数 = 把代码打包起个名字，好处是不用抄、改一处就够、main 变清爽。
  2. 结构：返回值类型  名字 （材料清单） { 怎么算 }。
  3. return 有两个作用：交出结果 + 立刻结束函数。
  4. 普通变量传的是副本，函数里改了外面不变 —— 要靠返回值送结果。
  5. 数组传进去，函数里改了外面会变 —— 这一点和普通变量不同。
两讲合起来，你已经能做什么
  • 用数组存一批数据，用循环处理它们
  • 把「求最大、求和、计数、查找」这些常见处理写成函数，反复使用
  • 把一道复杂的题拆成几个小函数，逐个实现
