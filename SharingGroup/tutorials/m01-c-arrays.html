数组初步

UME 项目组内部教程 · M01（Main） · 面向零编程基础成员

C++ 本讲：数组

怎么用这份文档

每个知识点都是「先讲清楚，再给代码，代码后面紧跟运行结果」。 建议对着代码自己敲一遍，再看输出对不对得上。 带紫色边框的词是术语，鼠标移上去会高亮。

本讲只需要你已经会 printf、scanf、if、for。 不涉及任何指针内容，可以放心看。

1为什么需要数组

假设要存一个班的 5 个成绩，用你已经会的方法，得开 5 个变量：

5 个独立变量复制
int s1, s2, s3, s4, s5;
s1 = 88;
s2 = 92;
s3 = 79;
s4 = 95;
s5 = 61;

5 个还行。那 50 个呢？500 个呢？而且想「把所有成绩加起来」， 你没法写一个循环，只能老老实实 s1 + s2 + s3 + ... 一路写下去 —— 这显然不行。

问题出在：这 5 个变量互相没有关系，程序没法用「第几个」去指代它们。

数组解决的就是这件事：把一批同类型的值排成一队， 从左到右编上号，然后就可以用「第几号」来访问任意一个， 于是循环也就用得上了。

一句话定义

数组 = 一排同类型的格子，每格有编号，编号从 0 开始。

你只要记住三件事：一排、同类型、编号从 0 起。

数组在脑子里长什么样

写 int a[5] = {88, 92, 79, 95, 61}; 之后，可以想象成 5 个挨着的格子：

88
a[0]
92
a[1]
79
a[2]
95
a[3]
61
a[4]

上面是格子里的值，下面是它的编号（下标）。把鼠标移到格子上看看。

最容易错的一点

5 个格子，编号是 0 1 2 3 4，没有 a[5]。 「长度是 5」和「最大下标是 4」是两件事，差 1。

2声明一个数组

语法和普通变量几乎一样，只多了一对方括号：

声明语法复制
类型名 数组名[长度];

对照着看就明白了：

普通变量数组含义
int score;int score[5];一个整数  /  一排 5 个整数
double h;double h[10];一个小数  /  一排 10 个小数
char c;char c[20];一个字符  /  一排 20 个字符
声明并查看长度复制
#include <stdio.h>

int main(void) {
    int a[5];        /* 5 个整数格子 */
    double d[3];     /* 3 个小数格子 */
    char s[20];      /* 20 个字符格子，常用来放一串文字 */

    /* sizeof 能问出「这个数组一共占多少字节」 */
    printf("a 占 %d 字节\n", (int)sizeof(a));
    printf("d 占 %d 字节\n", (int)sizeof(d));
    printf("s 占 %d 字节\n", (int)sizeof(s));

    /* 用「总字节数 ÷ 单个元素的字节数」就能算出元素个数 */
    printf("a 有 %d 个元素\n", (int)(sizeof(a) / sizeof(a[0])));
    return 0;
}
运行结果
a 占 20 字节
d 占 24 字节
s 占 20 字节
a 有 5 个元素

解读：一个 int 占 4 字节，5 个就是 20 字节；一个 double 占 8 字节，3 个就是 24 字节； 一个 char 占 1 字节，20 个就是 20 字节。 所以 20 ÷ 4 = 5，就算出了元素个数。

关于长度

方括号里的长度必须是编译时就能确定的整数。下面第一种写法可以，第二种不行：

  • int a[10]; 可以
  • int n = 10; int a[n]; 不要这样写 —— 换编译器可能报错

本讲统一用固定长度的写法，比如 a[100]， 够用就行，实际用几个由后面循环里的 n 决定。

3下标从 0 开始

这是初学者最不适应的一点，但记住就好：第一个元素的编号是 0，不是 1。

编号对照复制
int a[5] = {88, 92, 79, 95, 61};

/* 元素：   88    92    79    95    61   */
/* 下标：  a[0]  a[1]  a[2]  a[3]  a[4] */
/* 第几个：  1     2     3     4     5   */

为什么设计成从 0 开始？现在不必深究， 只要接受这个事实：下标 = 「第几个」减 1。

口诀：长度 n 的数组，合法下标是 0 到 n-1。 写循环时条件一定是 i < n，不是 i <= n。
越界会怎样

如果你写了 a[5]（长度 5 的数组），C 语言不会拦你， 程序可能照常跑、也可能乱跳、也可能直接崩。 这类错误最难查 —— 因为报错的地方常常不是出错的地方。

所以：循环边界要反复检查。后面第 9 节有专门的对照例子。

4访问与修改元素

写法是 数组名[下标]。它可以当普通变量用： 能读出来、能赋值、能参与运算、能塞进 printf。

读、写、算复制
#include <stdio.h>

int main(void) {
    int a[5] = {3, 1, 4, 1, 5};

    /* ① 读出来 */
    printf("a[0]=%d  a[2]=%d  a[4]=%d\n", a[0], a[2], a[4]);

    /* ② 改掉某一格 */
    a[0] = 100;
    printf("改完 a[0]=%d\n", a[0]);

    /* ③ 用元素参与运算，结果存回元素 */
    a[4] = a[0] + a[1];
    printf("a[4] = a[0]+a[1] = %d\n", a[4]);

    /* ④ 整个数组现在的样子 */
    printf("%d %d %d %d %d\n", a[0], a[1], a[2], a[3], a[4]);
    return 0;
}
运行结果
a[0]=3  a[2]=4  a[4]=5
改完 a[0]=100
a[4] = a[0]+a[1] = 101
100 1 4 1 101

注意第 ④ 行：a[0] 被改成了 100，a[4] 变成了 101， 而 a[1] a[2] a[3] 没动过 —— 说明改一格不影响别的格。

下标可以是表达式

方括号里不只能是数字，任何能得到整数的东西都行：

  • a[i] —— 用循环变量，最常见的用法
  • a[i + 1] —— 看下一个
  • a[n - 1] —— 看最后一个
  • a[i * 2] —— 跳着看

这一点是数组能用循环的前提。

5用循环遍历

「遍历」就是把每个格子挨个走一遍。因为下标是连续的整数，for 循环天生适合它。

标准写法（把它背下来）复制
int n = 5;
for (int i = 0; i < n; i++) {
    /* 这里用 a[i] 访问第 i 个元素 */
}

三个关键点，一个都不能错：

i = 0
从第一个开始，不是从 1
i < n
到第 n 个为止，不是 i <= n
i++
每次往后挪一格
正着遍历 / 倒着遍历复制
#include <stdio.h>

int main(void) {
    int a[5] = {3, 1, 4, 1, 5};
    int n = 5;

    /* 正着：0 → 4 */
    printf("正着：\n");
    for (int i = 0; i < n; i++) {
        printf("a[%d] = %d\n", i, a[i]);
    }

    /* 倒着：4 → 0 */
    printf("倒着：\n");
    for (int i = n - 1; i >= 0; i--) {
        printf("a[%d] = %d\n", i, a[i]);
    }
    return 0;
}
运行结果
正着：
a[0] = 3
a[1] = 1
a[2] = 4
a[3] = 1
a[4] = 5
倒着：
a[4] = 5
a[3] = 1
a[2] = 4
a[1] = 1
a[0] = 3
倒着遍历的三个细节
  • 起点是 n - 1（最后一个的下标）
  • 条件是 i >= 0，要写 >= 才能走到 0
  • 变化是 i--
倒着遍历的经典坑

不要把循环变量写成无符号类型（unsigned）。 因为 0 - 1 在无符号里会变成一个极大的数，循环永远停不下来。 初学阶段一律用 int i 就好。

6初始化写法大全

声明数组时可以顺手把初值填进去，用大括号 { }。 下面四种写法都很常用。

① 全写出来

完整初始化复制
int a[5] = {3, 1, 4, 1, 5};   /* 5 个格子全部填好 */

② 省略长度，让编译器数

长度自动推断复制
int b[] = {10, 20, 30};   /* 数一数是 3 个，等价于 int b[3] */

③ 只写一部分，剩下的自动补 0

部分初始化复制
int c[5] = {1, 2};   /* 前两个是 1、2，后面三个自动为 0 */

④ 全部清零（最常用）

清零惯用法复制
int z[5] = {0};   /* 只要给第一个 0，其余全部自动为 0 */

把四种放在一个程序里看看：

四种写法对照复制
#include <stdio.h>

int main(void) {
    int a[5] = {3, 1, 4, 1, 5};
    int b[]    = {10, 20, 30};
    int c[5] = {1, 2};
    int z[4] = {0};

    printf("a: %d %d %d %d %d\n", a[0], a[1], a[2], a[3], a[4]);
    printf("b: %d %d %d\n",       b[0], b[1], b[2]);
    printf("c: %d %d %d %d %d\n", c[0], c[1], c[2], c[3], c[4]);
    printf("z: %d %d %d %d\n",    z[0], z[1], z[2], z[3]);
    return 0;
}
运行结果
a: 3 1 4 1 5
b: 10 20 30
c: 1 2 0 0 0
z: 0 0 0 0

重点看 c 那一行：只给了 {1, 2}， 后面三格自动变成 0，不是随机数。

为什么 = {0} 这么重要

如果声明时不写初值，格子里的内容是不确定的垃圾值。 凡是「先累加、先计数」的数组，用之前一定要清零：

  • 累加：sum[i] += x; —— 如果 sum[i] 本来是垃圾，结果就废了
  • 计数：cnt[v]++; —— 同上

养成习惯：要累加或计数的数组，声明时一律 = {0}。

7读入一批数据

把 scanf 和循环、数组凑在一起，就是「读入 n 个数」的标准写法：

读入 n 个数复制
int n;
int a[100];

scanf("%d", &n);           /* 先读个数 */
for (int i = 0; i < n; i++) {
    scanf("%d", &a[i]);   /* 再一个一个读进数组 */
}
关于 & 这个符号

你已经学过 scanf("%d", &x) 的写法。 对数组元素，就照葫芦画瓢写成 &a[i] —— 把它当成 scanf 要求的固定格式记住就行，暂时不用管符号本身的含义。

（如果你看到别人写 scanf("%s", s) 读一串文字时没有 &， 那不是笔误，是另一种情况 —— 这个以后再讲。）

完整例子：读 5 个数并原样打印

读入 + 输出复制
#include <stdio.h>

int main(void) {
    int n;
    int a[100];

    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    printf("读到了 %d 个数：\n", n);
    for (int i = 0; i < n; i++) {
        printf("%d ", a[i]);
    }
    printf("\n");
    return 0;
}
运行结果（第 1 行是你敲进去的）
5
3 1 4 1 5
读到了 5 个数：
3 1 4 1 5
小技巧：scanf 不在乎空格和换行

输入 3 1 4 1 5 和分 5 行输入 3 ↵ 1 ↵ 4 ↵ 1 ↵ 5 效果完全一样。 %d 会自动跳过空白字符，所以你不用操心用户怎么敲。

8六个常用套路

数组的用法千变万化，但初学阶段真正高频的就下面六个。 把这六个练熟，绝大多数作业题都能拆解出来。

8.1 求和与平均

思路：准备一个 sum，循环里把每个元素加进去。

求和 / 求平均复制
#include <stdio.h>

int main(void) {
    int a[5] = {3, 1, 4, 1, 5};
    int n = 5;

    int sum = 0;                      /* ① 先置 0 */
    for (int i = 0; i < n; i++) {
        sum += a[i];                    /* ② 逐个累加 */
    }

    printf("sum = %d\n", sum);
    printf("avg = %.2f\n", sum / 5.0);   /* ③ 除以 5.0 而不是 5 */
    return 0;
}
运行结果
sum = 14
avg = 2.80
整数除法陷阱

如果把 sum / 5.0 写成 sum / 5，结果是 2 而不是 2.80。 因为两个整数相除，C 会丢掉小数部分（14 / 5 = 2）。

办法：除号两边至少有一个是小数，比如写 5.0，或者写 (double)sum / n。

8.2 最大值与最小值

思路：先假设第一个就是最大的，然后从第二个开始逐个挑战它。

求最大值复制
int mx = a[0];                /* ① 打擂：先让 a[0] 当擂主 */
for (int i = 1; i < n; i++) {  /* ② 从第 2 个开始挑战，注意是 1 */
    if (a[i] > mx) {
        mx = a[i];              /* ③ 赢了就换擂主 */
    }
}
printf("max = %d\n", mx);
求最小值：只改两处复制
/* 与求最大值相比只有两处不同：变量名 mx→mn，比较符 >→< */
int mn = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] < mn) {        /* 只改这里 */
        mn = a[i];
    }
}
printf("min = %d\n", mn);
两个最常见的错法
  • 初始值写 int mx = 0; —— 如果数组全是负数，答案就永远是 0，错了。 正确做法是用 a[0] 打擂。
  • 循环从 i = 0 开始 —— 不算错，但让 a[0] 和自己比了一次，白跑一趟。从 1 开始更清楚。

完整程序与结果

同时求最大最小复制
#include <stdio.h>

int main(void) {
    int a[6] = {88, 92, 79, 95, 61, 84};
    int n = 6;

    int mx = a[0], mn = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > mx) mx = a[i];
        if (a[i] < mn) mn = a[i];
    }
    printf("max = %d, min = %d\n", mx, mn);

    /* 顺便记下最大值在第几个（下标） */
    int pos = 0;
    for (int i = 1; i < n; i++) {
        if (a[i] > a[pos]) pos = i;
    }
    printf("最大值是 a[%d] = %d\n", pos, a[pos]);
    return 0;
}
运行结果
max = 95, min = 61
最大值是 a[3] = 95
要「最大值是多少」还是「最大值在哪」？

第二个循环没存最大值本身，而是存下标 pos。 因为只要知道下标，值随时能取（a[pos]）； 反过来只知道值，是查不出它在第几个的。需要位置时就记下标。

8.3 计数

思路：准备一个计数器，循环里碰到符合条件的就 ++。

统计等于 1 的个数复制
int a[5] = {3, 1, 4, 1, 5};
int n = 5;
int cnt = 0;

for (int i = 0; i < n; i++) {
    if (a[i] == 1) {
        cnt++;
    }
}
printf("1 出现了 %d 次\n", cnt);
运行结果
1 出现了 2 次

把条件换掉，就变成了完全不同的统计 —— 这是计数套路最方便的地方：

条件写法统计的是什么
if (a[i] == 1)等于 1 的个数
if (a[i] > 60)大于 60 的个数（及格人数）
if (a[i] % 2 == 0)偶数的个数
if (a[i] >= 60 && a[i] < 70)落在 60~69 之间的个数

8.4 查找

思路：从头挨个比，找到了就记下位置并 break； 找不到要能区分出来，所以位置先设成 -1。

查找某个值复制
int a[5] = {3, 1, 4, 1, 5};
int n = 5;
int target = 4;

int pos = -1;              /* ① 先假定「没找到」 */
for (int i = 0; i < n; i++) {
    if (a[i] == target) {
        pos = i;                /* ② 找到了，记下第几个 */
        break;                  /* ③ 不用再往后找了 */
    }
}

if (pos >= 0) {
    printf("找到 %d，在下标 %d\n", target, pos);
} else {
    printf("%d 不存在\n", target);
}
运行结果（target = 4）
找到 4，在下标 2

把 target 改成 9，输出就变成：

运行结果（target = 9）
9 不存在
为什么用 -1 而不是 0

下标 0 是合法位置（第一个元素）。 如果初始值设成 0，那么「没找到」和「在第 0 个找到」就分不清了。

-1 是个不可能出现的下标，正好用来表示「没有」。 这个技巧在编程里很常用。

8.5 逆序

「逆序」有两种完全不同的做法，别搞混。

做法一：另开一个数组，倒着搬过去

搬到新数组复制
int src[5] = {1, 2, 3, 4, 5};
int n = 5;
int rev[5];

for (int i = 0; i < n; i++) {
    rev[i] = src[n - 1 - i];   /* 关键：n-1-i */
}

for (int i = 0; i < n; i++) {
    printf("%d ", rev[i]);
}
printf("\n");
运行结果
5 4 3 2 1

理解 src[n - 1 - i] 的对应关系：

in-1-irev[i] = src[?]
04rev[0] = src[4] = 5
13rev[1] = src[3] = 4
22rev[2] = src[2] = 3
31rev[3] = src[1] = 2
40rev[4] = src[0] = 1

做法二：原地对调（不开新数组）

把第 1 个和倒数第 1 个换、第 2 个和倒数第 2 个换……换到中间就停。

原地交换复制
int a[5] = {1, 2, 3, 4, 5};
int n = 5;

for (int i = 0; i < n / 2; i++) {   /* 只走一半！ */
    int t = a[i];                     /* 三步交换，需要临时变量 */
    a[i] = a[n - 1 - i];
    a[n - 1 - i] = t;
}

for (int i = 0; i < n; i++) {
    printf("%d ", a[i]);
}
printf("\n");
运行结果
5 4 3 2 1
为什么要 i < n / 2

如果写成 i < n，就会把已经换好的又换回去 —— 转一圈等于没动。只要换到中间就够了。

另外，交换两个格子必须借一个临时变量 t。 直接写 a[i] = a[j]; a[j] = a[i]; 是错的（两格会变成一样）。

8.6 用辅助数组统计频次

这是数组最漂亮的一类用法：把「值」当下标，直接数出每个值出现几次。

比如给一串 0~9 的数字，统计每个数字出现多少次：

频次统计复制
#include <stdio.h>

int main(void) {
    int a[8] = {2, 5, 2, 7, 5, 2, 9, 7};
    int n = 8;

    int cnt[10] = {0};    /* ① 10 个格子，分别管数字 0~9，先清零 */

    for (int i = 0; i < n; i++) {
        cnt[a[i]]++;          /* ② 把「值」当编号去 ++ */
    }

    for (int v = 0; v < 10; v++) {   /* ③ 扫一遍看谁不为 0 */
        if (cnt[v] > 0) {
            printf("%d 出现 %d 次\n", v, cnt[v]);
        }
    }
    return 0;
}
运行结果
2 出现 3 次
5 出现 2 次
7 出现 2 次
9 出现 1 次

关键是 cnt[a[i]]++ 这一句，拆开看：

a[i]
取出第 i 个值
比如 2
cnt[2]
找到「管 2 的那个格子」
cnt[2]++
给它加 1
这个套路还能怎么变

只要把「值 → 下标」的对应关系换一换，同一招能解决很多题：

  • 成绩 0~100 → 开 int cnt[101]，直接统计每个分数的人数
  • 小写字母 a~z → 开 int cnt[26]， 用 cnt[ch - 'a']++（这一招等你学了字符运算再用）

核心永远是那句：让值本身告诉你该去哪个格子。

再练一个：分段统计人数

需求：把成绩分成 5 段，数出每段各有多少人。

分数段统计复制
#include <stdio.h>

int main(void) {
    int a[6] = {88, 92, 79, 95, 61, 84};
    int n = 6;

    /* 0: 0-59   1: 60-69   2: 70-79   3: 80-89   4: 90-100 */
    int band[5] = {0};

    for (int i = 0; i < n; i++) {
        int s = a[i];
        if (s < 60)      band[0]++;
        else if (s < 70) band[1]++;
        else if (s < 80) band[2]++;
        else if (s < 90) band[3]++;
        else                band[4]++;
    }

    for (int i = 0; i < 5; i++) {
        printf("band[%d] = %d\n", i, band[i]);
    }
    return 0;
}
运行结果
band[0] = 0
band[1] = 1
band[2] = 1
band[3] = 2
band[4] = 2

核对一下：61 在 60~69（1 人）；79 在 70~79（1 人）； 88 和 84 在 80~89（2 人）；92 和 95 在 90~100（2 人）。共 6 人，对上了。

9常见错误

下面这些是批改作业时最常看到的错法，逐个对照一遍，能省你很多调试时间。

错误 1 · 循环条件写成 <=（越界）

对比复制
int a[5];

/* ❌ 错：i 会取到 5，而 a[5] 不存在 */
for (int i = 0; i <= 5; i++) { ... }

/* ✅ 对：i 只取 0~4 */
for (int i = 0; i < 5; i++) { ... }

这里就体现出用变量 n 表示长度的好处：i < n 一眼就能看出对不对。

错误 2 · 声明了长度，却按「第几个」去访问

对比复制
int a[5] = {88, 92, 79, 95, 61};

printf("%d\n", a[1]);   /* ✅ 92 —— 第 1 个元素 */
printf("%d\n", a[5]);   /* ❌ 越界！第 5 个是 a[4] */
正确输出
92
61

错误 3 · 忘记给累加/计数数组清零

对比复制
/* ❌ 错：cnt 里是垃圾值，++ 之后结果无法预料 */
int cnt[10];
cnt[3]++;

/* ✅ 对：先清零 */
int cnt[10] = {0};
cnt[3]++;

错误 4 · 交换两格时忘了临时变量

对比复制
/* ❌ 错：第一句就把 a[i] 覆盖了，第二句等于白写 */
a[i] = a[j];
a[j] = a[i];

/* ✅ 对：借一个临时变量 */
int t = a[i];
a[i] = a[j];
a[j] = t;

错误 5 · 整数除法丢小数

对比复制
int sum = 499, n = 6;

printf("%.2f\n", sum / n);         /* ❌ 83.00 —— 先做整数除法，小数已经丢了 */
printf("%.2f\n", sum / 6.0);       /* ✅ 83.17 */
printf("%.2f\n", (double)sum / n); /* ✅ 83.17 —— 另一种写法 */
运行结果
83.00
83.17
83.17

错误 6 · 求最大值时初始值给 0

对比复制
/* 数组全是负数时： */
int a[3] = {-5, -2, -8};

int mx = 0;        /* ❌ 结果 0，但数组里最大的其实是 -2 */
int mx = a[0];     /* ✅ 用第一个元素打擂，结果 -2 */

本讲要记住的四句话
  1. 数组是一排同类型的格子，编号从 0 开始。
  2. 长度 n 的数组，最后一个下标是 n-1，循环写 i < n。
  3. 要累加或计数的数组，声明时写 = {0}。
  4. 求最大值用 a[0] 打擂，不要给 0。
