# UME 编辑器（Qt / QWidget）

用 Qt 重写的桌面版，与 `web/UME.html` 那套网页版是同一件事的两个实现。
设计取向：**QWidget**、**竖排自绘**、**分页**、**富文本**。

## 怎么运行

工具链（与 `tools/qt/a02` 同一套）：

| 组件 | 位置 |
|---|---|
| Qt 6.12.0 mingw_64 | `D:\Qt\6.12.0\mingw_64` |
| MinGW 13.1 | `D:\Qt\Tools\mingw1310_64` |
| CMake / Ninja | `D:\Qt\Tools\...` |

装在别处就改 `build.bat` 顶部三行路径。

```bat
:: 1) 配置 + 编译（第一次会自动跑 cmake，之后只跑 ninja）
app\build.bat

:: 2) 运行
app\run.bat                      :: 打开编辑器
app\run.bat 词表.txt              :: 打开并载入文件
```

**为什么要用 `run.bat`**：`ume.exe` 依赖 Qt 的 DLL，
直接双击 exe 会报「找不到 Qt6Widgets.dll」。
`run.bat` 会把 `D:\Qt\6.12.0\mingw_64\bin` 塞进 `PATH` 再启动。

> 注：`.bat` 里的注释一律用英文 —— `cmd.exe` 按 OEM 代码页读批处理，
> 写成 UTF-8 中文会把命令拆坏。

## 命令行模式（不用开窗口）

```bat
:: 光标 / 命中 / 选区自检，并出两张图
app\run.bat --selftest 样本.txt --outdir out

:: 把纯文本渲染成一页 PNG
app\run.bat --render 样本.txt --out 第1页.png --scale 2

:: 指定纸张与页边距（pt，四边独立）
app\run.bat --render 样本.txt --out a.png --paper A4 --margin 56.7,56.7,56.7,56.7
```

`--selftest` 走的是真实的 `QKeyEvent`，把每一步的 `pos / sel / caret` 打出来，
相当于页面的「逐像素对拍」在光标上的版本。

## 界面分成两块

| 区域 | 内容 | 谁在管 |
|---|---|---|
| **开始工具栏**（上） | 字体、字号、颜色 | `UmeFormatBar`，即「文字格式」，跟随光标/选区 |
| **布局控制**（右侧停靠面板） | 纸张与页边距、最小列宽、辅助线 | `UmeLayoutBar`，即「版面」，与文字格式无关 |

格式状态按 Word 的规矩来：

- 选中一个词 → 工具栏显示**这个词的**字体/字号/颜色；
- 选区里格式不统一 → 对应框**留空**（字体显示「多种字体」，字号显示「多种」，色块打红叉）；
- 用户指定一个值 → 选区里所有字符统一成它，框里随即显示该值。

## 代码结构

| 文件 | 职责 |
|---|---|
| `src/umepage.h` | 页面模型：纸张 + 四边页边距 + 预置（A4 / B5 / 16 开 / Letter） |
| `src/umelayout.*` | 竖排布局：块 → line → 列 → 页，列自左向右 |
| `src/umeview.*` | 自绘视图：绘制、光标、命中、选区、键盘、缩放、离屏渲染 |
| `src/mainwindow.*` | 工具栏（字体 / 字号 / 列距 / 辅助线 / 纸张） |
| `src/main.cpp` | GUI 入口 + `--render` / `--selftest` |

## 几何约定（踩过的坑）

- 一条 `QTextLine` 横向排布，宽度 = 正文区**高度**，然后整条 `rotate(90)`；
  局部 `x` → 屏幕 `+y`（列向下），局部 `y` → 屏幕 `−x`。
- 这支字体里蒙文字形的墨迹落在基线的**局部 +y 侧**，所以基线要右移 `inkAbove`
  才能让墨迹左缘压住列左边（实测差 16.7pt，不修会画进页边距）。
- 竖排光标是**横向短条**（垂直于书写方向），不是竖线。
- 列距自动值取 `max(字号 × 1.7, 墨迹宽 × 1.3)`；直接用 `fm.height()` 会得到
  34pt（14pt 字号），列与列之间空得像隔了一条街。

## 插入功能区

工具栏「插入」：**图片… / 表格… / 链接…**，菜单「插入」同样三项。

| 功能 | 行为 |
|---|---|
| 图片… | 选文件 → 插入**行外图片块**，默认**列游标**模式，按 96dpi 折算尺寸，超过正文区 80% 自动缩小 |
| 表格… | 弹窗填**行数 / 列数**（微调框）→ 插入表格，默认列游标 |
| 链接… | 输入网址 → 套在选区上或插入链接文字 |

## 图片选择与控制手柄

点选图片后出现 **9 个手柄**：四角 + 四边中点（缩放）+ 右侧一个（旋转）。

- 四角：等比缩放（`keepAspect` 打开时联动跨列数）
- 四边：单轴缩放（左右改跨列，上下改高度）
- 旋转手柄：拖动改 `rotation`
- 拖对象本体：上下移动（写 `offsetPt`）

## 限制（防止夸张操作毁掉整篇布局）

`UmeView::applyWideObject()` 在写回前统一钳制，越界会记日志 `[wide] clamped …`：

| 属性 | 范围 |
|---|---|
| 跨列数 | 1 … ⌊正文区宽 / 最小列宽⌋（上限 48） |
| 高度 | 8 pt … 正文区高 |
| 纵向偏移 | ± 正文区高 |
| 旋转 | 归一化到 0–360 |

另外排版层还有两条硬约束：

1. 宽对象**放不下先试下一列，再换页**，绝不硬塞到列底；
2. 图片插入时若超高正文区 80%，按比例缩小后再插入。

## 宽对象（表格 / 图片）

横跨多列的对象单独成一层，**与文字格式、版面设置互不共享状态**：

| 层 | 管什么 | 类 |
|---|---|---|
| 文字格式 | 字体、字号、颜色 | `UmeFormatBar` / `UmeFormatState` |
| 版面设置 | 纸张、页边距、最小列宽 | `UmeLayoutBar` / `UmeSettings` |
| **宽对象** | 排版方式、跨列、高度、位置、表格行列 | `UmeWideBar` / `UmeDoc::WideProps` |

### 两种排版方式

| 方式 | 行为 |
|---|---|
| **独占整列**（`WideWrap::Span`） | 对象吃掉 K 列的宽度，后面的文字从它下游的列开始 |
| **文本围绕**（`WideWrap::Bubble`） | 对象只占一块矩形，同一列里它下面的文字从下方接着排 |

实现是「条带游标」：每 stripW 宽一个条带，`relayout()` 维护 `条带 → 已达到的 y`。
对象占用的条带游标推 `top + h`，文字列占用的条带游标推到列底。
放不下时先试下一列条带，一列都放不下才换页 —— 对象**从不硬塞到列底**。

### 数据存在哪

- 表格：属性存在 **`QTextTableFormat`** 里。增删行列会重建单元格块，
  存块格式会丢（实测过）。
- 图片等：存在块格式里。
- 属性：`kind / wrap / span / heightPt / offsetPt / keepAspect / naturalW / naturalH / rotated`。

### 面板

`UmeWideBar`（右侧停靠，与「布局控制」并成标签页），只在光标落在宽对象里时启用：

- 排版方式：独占整列 / 文本围绕
- 跨列数、高度、缩放保持比例、原始尺寸
- 位置：上移 / 下移 / 复位（`offsetPt`）
- 表格：+ 行 / − 行 / + 列 / − 列（跨列数随列数同步）

### 流向

`UmeLayout::Flow { Ltr, Rtl }`：默认 Ltr（自左向右）。
`relayout()` 已按 `flow` 分支推进列；换成 Rtl 只需把默认值改掉并检查分页方向。

## 预留能力：链接 / 表格 / HTML

这三项功能尚未做完，但底层接口已经就位，接功能时不用再动排版内核。

### 超链接

| 接口 | 作用 |
|---|---|
| `UmeDoc::applyLink(cursor, url, text)` | 有选区就套在选区上，否则插入链接文字（蓝色 + 下划线 + `anchorHref`） |
| `UmeDoc::linkAt(cursor)` | 光标处的链接（光标在末尾时看前一字符） |
| `UmeDoc::allLinks(doc)` | 文档内所有链接（去重） |
| `UmeView::insertLink(url)` / `linkAtCursor()` | 视图层封装 |

- 链接下划线在竖排里画成**与列平行的细线**（贴墨迹左侧）—— 我们逐字形绘制，
  `QTextDocument` 不会替我们画下划线。
- 悬停链接显示手型，`Ctrl + 点击` 交给系统打开（写日志 `[link] open …`）。

### 表格

- `UmeDoc::insertTable(cursor, rows, cols)`：插入表格，首行加粗作表头。
- `UmeDoc::inTable(cursor)` / `tableSize(cursor)`：判断与规格。
- **排版侧只做了安全处理**：表格单元格里的段落按普通段落排成若干列，
  `UmeLayout::tableBlocks()` 会给出这类段落的数量。真正的表格框线、单元格合并、
  跨列排版尚未实现 —— 接功能时在这里扩展。

### 富文本转 HTML

- `UmeDoc::toHtml(doc)`：`QTextDocument::toHtml()` 之后注入一段 CSS，
  补上 `writing-mode: vertical-rl` 与字体栈（`Noto Sans Mongolian → SimSun → Times`）。
  `toHtml()` 本身不知道直排，也不认识我们的列模型。
- 命令行：`--html out.html`；菜单：文件 → 导出 HTML…。
- 实测导出件含 `<a href>`、`<table>`、`writing-mode`。

## 颜色

- 「开始」工具栏的色块按钮：**自动（黑色）/ 常用色板（12 色）/ 更多颜色…**。
- 语义与字体、字号一致：改颜色只作用于**选区**；没有选区时只改「接下来输入的字」。
- 选区里颜色不统一时，色块显示为灰底红斜线（与字体「多种字体」同理）。
- 渲染时按格式区间取色：`rotate` 的蒙文/拉丁用 `fillPath(path, color)`，
  直立汉字用 `setPen(color)`，两条路径取同一个颜色。
- **必须自己 `QTextLayout::setFormats()`**：我们绕开了 QTextDocument 的默认排版
  （自己 `beginLayout`），`formats()` 不会自动填。没填的话它永远是空列表，
  按区间取颜色/字体全部落空 —— 表现就是「改了颜色但文字还是黑的」。
  实现在 `UmeLayout::relayout()` 里，按 block 的片段逐个生成 FormatRange。
- 兜底顺序：格式区间 → 块格式 → 基础格式。**不能写死黑色** ——
  整段同色时 `QTextLayout::formats()` 是空的（只记录与块格式不同的部分）。
- 命令行验证：`--render … --color "#c00000"`。

**光标颜色跟随输入色**：光标画成「接下来输入的文字颜色」，与工具栏色块、实际打字三者一致。
浅色（黄、白）在白纸上会隐形，所以亮度超过 0.72 的会压暗（`#ffff00` → `#747400`）。
光标落在已着色的文字上时，会把该处的颜色收作插入色（`adoptColorAtCursor()`）——
只收颜色，不收字体字号（字体要按脚本自动分配）。

## 混排的方向规则

| 文字 | 方向 | 实现 |
|---|---|---|
| 蒙文、拉丁字母、数字、括号破折号引号 | 随列旋转（rotate 90°） | `QRawFont::pathForGlyph` + 旋转画 |
| 汉字、假名、韩文、注音 | **直立** | 同一路径，不旋转，居中在本槽位 |

- `QTextLine::glyphRuns()` 必须显式要 `RetrieveGlyphIndexes | RetrieveGlyphPositions | RetrieveStringIndexes | RetrieveString`，否则拿不到 `sourceString()`，判断不了该不该直立。
- **不要用 `QPainter::drawGlyphRun()` 画**：实测离屏渲染里一个墨点都不出（墨迹像素 0）。两条分支统一走「取字形轮廓 + fillPath」。
- **坐标单位是「96dpi 像素」，画布是 pt**：`QTextLayout` 的 glyph 位置与 `QRawFont::pathForGlyph` 的轮廓都是 96dpi 像素，画进 pt 画布要乘 `72/96 = 0.75`，否则整页字会大 33%、位置也偏。
- 直立字改用 `drawText`：「一字一格」不需要连字，走 Qt 的文本绘制比轮廓稳（轮廓牵扯上面的单位换算）。
- `rotate(90)` 之后局部 −y 映射到屏幕 **+x**，墨迹在基线右侧；绘制、光标、选区三处统一用 `columnInkLeft()` 取落点，别各算各的 —— 之前就是三处各用一套坐标，出现「高亮在左、字在右」。
- 颜色按格式区间反查：把 `QTextLayout::formats()` 的字符区间用 `cursorToX` 换成行内 x 区间，再按字形位置取色。
