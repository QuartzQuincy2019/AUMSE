# M2 编辑与格式

## 改字号只改了行距，字形没变大

**现象** 字号 14 → 28，字还是原来大小，只是列间距变宽。

**错因** `QTextDocument` 在插入时就把字体记进每个 fragment，
之后 `setDefaultFont()` 对**已有文字无效**。

**修法** 合并一个基础 `QTextCharFormat` 到全文（`applyBaseFontToDocument()`）。
实测同一行推进宽度 87.0 → 170.0pt（1.95 倍）。

## 切换字族没有任何变化

**现象** 换字体，画面不动。

**错因** 同上（fragment 里存的是插入时的字体）。

**修法** 同上，改为按选区合并字符格式。

## 只选了一个词，改字号却影响整篇

**现象** 选 3 个字改字号，整篇都变了。

**错因** 布局度量（基线、列距）取自「当前面板字体」，改一次全篇重算。

**修法** 度量基准在载入时冻结（`m_metricsFamily / m_metricsPt`），
改格式只重排不改基准。实测换字体前后 `ascent/descent/pitch/firstColumn.left` 完全一致。

## 一启动字体是 Amglang，不是设置里的 Noto

**现象** 启动后显示的是 Menk Amglang Tig。

**错因** 换文档时 `applyBaseFontToDocument()` 因为 `m_appliedFamily` 已记录而提前返回，
新文档没被刷。

**修法** `setDocument()` / `openFile()` 时先 `resetBaseFont()` 清掉记忆。

## 选中文本后，格式控件仍显示上一次的值

**现象** 选一个 14pt 的词，字号框还停在上一个词的 30pt。

**错因** 控件只被「用户上次设置」驱动，没有随光标/选区回读。

**修法** 引入 `UmeFormatState`（family / pointSize / color + 三个 `*Mixed`），
按选区逐片段比较；一致就显示，不一致留空（「多种字体」「多种」、色块红斜线）；
用户指定后又显示回来。实测混合选区 `sizeMixed=1`，统一后 `sizeMixed=0 / 14.0`。

## 输入法上屏卡 586ms

**现象** 敲 MENGGU 选「蒙古」，卡半秒，然后排版乱掉。

**错因** 每列都新建 `QFontMetricsF`，并对**整段文字**做 `tightBoundingRect`。
文字含汉字时会触发回退字体解析，一次几百毫秒，按列数翻倍。

**修法** 字体度量按 `(族名, 字号)` 缓存；墨迹只量前 16 个字符。
实测同一文档 `relayout` 586ms → 1ms（进程内首次 214ms 是 Qt 字体缓存，不在打字路径上）。

## 颜色改了但文字还是黑的

**现象** 色块显示红色，正文仍黑。

**错因** 我们绕开 `QTextDocument` 的默认排版（自己 `beginLayout`），
**没有 `setFormats()`**，于是 `QTextLayout::formats()` 永远为空，
按区间取色一次都没命中，全部落到兜底黑。

**修法** 在 `UmeLayout::relayout()` 里按 block 的片段生成 `FormatRange` 喂给布局；
取色兜底改为「格式区间 → 块格式 → 基础格式」，不再写死黑色。
实测给前 5 字上红：红像素 0 → 84；整篇红色 8430 红 / 0 黑。

## 格式边界处多出一个很小的重影字

**现象** 段落里既有蒙文又有汉字时，汉字上方多画了个小号同字。

**错因** 判定「这个字形属于哪个字符」时取格子**正中间**（0.5），
窄字形会正好落在下一个字符的起点上，把下一字的汉字当成这一格的内容。

**修法** 取样点改 0.35，并给字号加钳制（半个字～两个字）。

## 光标颜色不跟输入色

**现象** 选了红色，光标仍是黑的，看不出「下一笔会写什么颜色」。

**错因** 光标一律用写死的 `0x111111` 画。

**修法** 光标取 `m_baseFormat` 的前景色；亮度 > 0.72 的自动压暗
（`#ffff00` → `#747400`），否则浅色光标在白纸上等于隐形。
光标移到已着色文字上时，顺带把该处颜色收作插入色（只收颜色，不收字体字号）。
实测：红色文字处光标 `#cc0000`。

## 插图块把整段正文推进了图片块

**现象** 插入图片后，页面只剩图片占位，原来的文字全部消失。

**错因** `insertBlock()` 停在块首时会**分割**当前块：原文本被推进新块，
而宽对象属性正好打在这个新块上 —— 于是「有文字的块」被当成图片对象跳过排版。

**修法** 先把光标 `movePosition(EndOfBlock)` 再插块，保证新块是空的。

## 表格单元格文字不跟随格式

**现象** 给整篇上红色，正文变红，表格里的字还是黑的；字号、粗细同样无效。

**错因** 表格单元格的排版是绘制时现做的：`lay->beginLayout()` 之前没有
`setFormats()`。我们自己接管排版时，格式区间必须手动喂进去，
否则 `line.draw()` 只能按默认格式画。

**修法** 抽出 `UmeView::setLayoutFormats(lay, block)`，按片段生成 FormatRange，
在单元格重排前调用；同时去掉绘制前那句写死的 `setPen(QColor(0x11,0x11,0x11))`。
实测整篇上红后表格区域红像素 113、近黑 0。
