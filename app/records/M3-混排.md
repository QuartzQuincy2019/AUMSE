# M3 混排（汉字直立与标点）

## 汉字不直立，跟着英文一起躺倒

**现象** 竖排一列里，汉字横躺着。

**错因** 整行用 `QTextLine::draw()` 一次性画完，整行都套了 `rotate(90)`。

**修法** 改成逐字形绘制：蒙文/拉丁/标点随列旋转，汉字/假名/韩文直立。

## 汉字时立时躺，取决于前面有没有空格

**现象** 「monggol 成吉思汗」里汉字躺倒；换一行又正常。

**错因** 直立判定依赖 `QGlyphRun::sourceString()`，而 Qt **经常给空串**；
后来改成整段按「首字形位置」判，首字形落在空格上就整段判错。

**修法** 逐字形判定：先算槽位，再取槽位内的一点反查字符
（`line.xToCursor`），按该字符决定直立与否。

## 汉字下端被裁掉

**现象** 汉字每一笔的下缘都不见一截。

**错因** `QPainter::drawText(QRectF, …)` 会按矩形**裁剪**，
而给的格子高度是排版步进（14pt 字约 14pt），装不下 1.2em 的字身。

**修法** 改为按**基线点**绘制 `drawText(QPointF, …)`，没有矩形就没有裁剪。

## 汉字互相压叠、标点缩成米粒

**现象** 一行汉字挤在一起，句号冒号引号小得看不见。

**错因** 汉字与中文标点被**蒙文字体**排版。主字体没有这些字形，步进只有半个字宽；
而绘制时字形来自回退字体，于是字大格小，必然压叠。
字形探针实测：`runs=15`，`[SimSun 7]` 夹着 `[Noto 1 ？]`、`[Noto 3 ：""]`。

**修法** 把「用哪个字体排」与「怎么摆」分开：`isCjkLike()` 覆盖汉字与中文标点，
载入与打字时按脚本切段落到 `cjkFamily()`。实测探针变成 `runs=2 [SimSun 31]`。

## 标点比正常小一圈

**现象** 句号冒号引号明显偏小。

**错因** 直立字按「格子高度」定字号。标点也走这条路，而标点的步进比字身窄。

**修法** 用字符**自身**的字号，格子只负责定位。

## 问号叹号被转了 90°

**现象** 竖排里的 `？` 躺倒，像怪符号。

**错因** 凭印象把 `？！` 当成「竖排要转 90°」。

**修法** 查 W3C [clreq §2.1.2](https://www.w3.org/TR/clreq/#major_differences_between_horizontal_and_vertical_writing_modes)：
点号（顿号、逗号、分号、**冒号、句号、问号、叹号**）「直、横排方向一致」，
即**不旋转**；中国大陆规范要求直排时贴**字面右上角**。按此改。

## `drawGlyphRun` 离屏渲染不出墨

**现象** 换成逐字形后，纯蒙文页面**整页空白**（墨迹 0 像素）。

**错因** `QPainter::drawGlyphRun()` 在离屏平台下不落墨（诊断显示 run 正常、
9 个字形都在、`rawFont` 有效，就是画不出来）。

**修法** 旋转支改走 `QRawFont::pathForGlyph()` + `fillPath()`。

## 整页字大了 33%、位置也偏

**现象** 逐字形绘制后，字比原来大一圈。

**错因** `QTextLayout` 的字形位置与 `QRawFont` 的轮廓都是 **96dpi 像素**，
画布是 **pt**，少乘了 `72/96`。

**修法** 绘制时 `scale(kPxToPt)`；绘制、光标、选区、命中四处统一。

## 巨大黑块 / 字飞出去

**现象** 偶尔出现一个占满半页的黑块，或一个字跑到远离文本的地方。

**错因** 末字形槽位取「剩余长度」时，跨 run 会拿到整行宽度，槽位有几百 pt。

**修法** 末字形取 `min(自身推进量, 剩余长度)`，并对字号做半个字～两个字的钳制。
