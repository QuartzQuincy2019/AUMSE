# 构建与工具链

## PowerShell 脚本不让跑

**现象** `无法加载文件 …\*.ps1，因为在此系统上禁止运行脚本`。

**错因** 执行策略限制。

**修法** 改用 `.bat`（`app/build.bat`、`app/run.bat`）。

## `.bat` 里有中文就报 `'m' 不是内部或外部命令`

**现象** 双击脚本，命令行报一串莫名其妙的单字母错误。

**错因** cmd 按 OEM 代码页读 `.bat`，UTF-8 中文注释被拆成乱码指令。

**修法** 两个脚本**只写 ASCII**，中文说明放 `README.md`。

## 编译报 `cannot open output file ume.exe: Permission denied`

**现象** 改完代码编译失败，报权限错误。

**错因** 上一次启动的 `ume.exe` 还开着，文件被锁。

**修法** 先结束进程再编译；已写进 `README.md` 的「已知问题 / 排查」。

## 双击 `ume.exe` 起不来（缺 Qt DLL）

**现象** 直接运行 exe 没有任何窗口。

**错因** 没有把 Qt 的 bin 目录加进 `PATH`。

**修法** 统一用 `app/run.bat` 启动（脚本里设置 `PATH`）。

## 离屏渲染看不到真正的字体

**现象** `--fonts` 只列出 1 个字体族；字体对比全部相同。

**错因** `QT_QPA_PLATFORM=offscreen` 下平台字体库是空的（真实平台 476 个）。

**修法** 字体相关验证一律不加 offscreen；自检里也避免依赖具体字体。

## 沙箱里写 `.shots/` 与 `%TEMP%` 被拒

**现象** 程序往这两个目录写图失败。

**错因** 文件 ACL 限制。

**修法** 一律先渲染到 `app/build/`，需要长期保留再复制到 `.shots/`。

## 日志里打印成 `%.1f` 字面量

**现象** `[wide] snap height %.1f → %.1f`，数字没被替换。

**错因** 把 printf 的占位符写进了 `QStringLiteral` 再 `.arg()` ——
`QString::arg` 只认 `%1/%2`（可带宽度/精度）。

**修法** 改成 `%1` / `%2` 并给 `.arg(v, 0, 'f', 1)`。查日志时这点很要命：
看不到真实数值，等于没日志。
