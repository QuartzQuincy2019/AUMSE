# 交互与吸附

宽对象的**操作命中**与**操作吸附**规则。与渲染无关，单独一份，便于以后加图片/表格/其他对象时复用。

## 旋转以「对象中心」为轴

设计要点（手绘推导）：

```
(a,b)  图片旋转中心（= 对象包围盒中心）
(x,y)  拖曳开始位置
(x',y') 光标当前位置
θ      旋转角 = ∠((x',y') − (a,b)) − ∠((x,y) − (a,b))
```

只看**方向差**，不看距离：`L1`、`L2` 长度再变也不影响角度。

```cpp
// UmeInteract::dragAngleDelta(center, from, to)
angleOf(to, center) - angleOf(from, center)
```

容易写错的两处：

- 用「手柄位置」当起点 × 应当用**按下时的光标位置**（手柄中心与光标未必重合）；
- 每次移动都拿「上一次的旋转角」累加 × 应当用**拖曳开始时的角度 + 本次角度差**，
  否则会漂移。

## 角度吸附

用户想停在 0/45/90/135/180…，但手不可能准。规则：

| 参数 | 值 |
|---|---|
| 吸附步长 | 45° |
| 容差 | ±8° |
| 超出容差 | 保持自由角度（不强吸） |

```cpp
UmeInteract::snapDegrees(43.5) == 45
UmeInteract::snapDegrees(20)   == 20   // 自由角度
```

实测：`0→0  3→0  20→20  43.5→45  46→45  88→90  133→135  178→180  270→270`。

## 拖曳捕获（光标不会一直停在手柄上）

按住手柄拖动时，光标一旦移动就会**离开手柄矩形**。若每次移动都重新做命中测试，
拖曳会立刻中断。所以：

1. 按下时判定一次命中，记下 `m_wideDrag` 的类别；
2. 移动时**不再做命中测试**，直接按已记录的类别应用；
3. 松开时才清空。

这也是「缩放手柄会跑」的原因：改变大小后手柄位置立刻变化，
只有捕获才能让拖曳连续。

## 手柄随对象旋转；命中要反向旋转

对象旋转后，9 个手柄跟着转（视觉位置变了）。如果命中测试还按未旋转的矩形算，
就几乎点不中。

做法：

```
视觉：  handle = rotatePoint(未旋转点, 中心, 角度)
命中：  local  = rotatePoint(光标,     中心, −角度)   // 反向转回去
        再与「未旋转手柄矩形」比较
```

再加**命中容差 5 pt**（手柄本身只有 6 pt 见方，鼠标不可能精确压住）。

## 悬停反馈：光标形状要跟着转

鼠标移到控制手柄上，光标必须换成对应的缩放/旋转光标；否则用户不知道这一格是干什么的。

难点与手柄命中相同：**光标方向也得随对象旋转**。

```
本地方向角（左上 225°、右下 45°、上 270°、右 0° …）
      + 对象旋转角
      → 归到最近的 45° 扇区
      → 扇区决定光标：0/4 水平、2/6 竖直、1/5 ↘、3/7 ↙
```

实测（`cursorProbe()`）：

| 旋转 | 四角 | 上下边 | 左右边 | 旋转手柄 |
|---|---|---|---|---|
| 0° | F B B F | V V | H H | R |
| 45° | V H H V | B B | F F | R |
| 90° | B F F B | H H | V V | R |

（F = 斜向 `SizeFDiag`，B = 另一条斜向 `SizeBDiag`，V/H = 竖/横，R = 自制旋转光标）

Qt 没有内置的旋转光标，用 `QPainter` 画了一段圆弧加箭头（`UmeIcons::rotateCursor()`），
hotspot 放在正中。

对象本体上则是 `SizeAllCursor`（可拖动），链接上是手型，其余是 I 形光标。

## 鼠标光标：竖排里要横过来

**现象** 鼠标移到正文上，光标是竖着的 I 形 —— 但这是直排，插入方向是**上下**的。

**错因** 直接用 `Qt::IBeamCursor`。系统 IBeam 是按横排设计的（竖杠 + 上下横线）。

**修法** 自制一个**转 90° 的 I 形**光标（`UmeIcons::textIBeam()`）：

- 正文悬停用它；链接上仍用系统手型；对象手柄上用缩放/旋转光标。
- 视图构造时也设成默认光标，避免鼠标刚进入时先闪一下竖 I。

形状照「**宽翼缘工字钢**」的截面画：两端是竖的**翼缘**，中间是较薄的**腹板**，
整块实心；直排时把工字钢转 90°，翼缘落在左右两侧。

```
        │▌     ▐│        ← 翼缘（厚）
        │▌━━━━━▐│        ← 腹板（薄）
        │▌     ▐│
```

| 参数 | 值 | 说明 |
|---|---|---|
| 画布 | 32 逻辑单位（2 倍屏 64px） | ≈ 24pt，与 14pt 字的一行相当 |
| 翼缘厚 | 3.2 | **必须比腹板厚**，否则看起来是「H」不是工字钢 |
| 腹板厚 | 1.9 | |
| 白描边 | 1.8 | 深色/彩色文字上都看得清 |
| 热点 | 正中心 | 指示插入位置 |

演进过程：细线版（24 画布、横线 12）→ 加长版（32、22）→ 工字钢实心版（4.6/3.0）→ **调细版（3.2/1.9）**。
细线版看起来像「小叉子」，改成实心截面后与正文行高的「一致感」才够。

### 顺序

悬停判断的顺序必须与按下时一致，否则会出现「看着是缩放光标，按下去却在拖对象」：

1. 手柄（缩放/旋转光标）
2. 对象本体（移动光标）
3. 链接（手型）
4. 文字（I 形）

## 优先级

按下时依次判断，命中即返回：

1. **手柄**（当前选中对象的 9 个手柄）
2. **对象本体**（点在包围盒里 → 选中并准备移动）
3. 文字（光标命中 / 拖曳选区）

点中对象本体时把光标也移进对象所在块，右侧「宽对象格式」面板才能读到属性。

## 限制

- 旋转角归一化到 `[0,360)`；
- 缩放后跨列数、高度、偏移都在 `applyWideObject()` 里统一钳制（见 README「限制」）；
- 拖曳中不改选区、不改光标，避免与文字拖选互相干扰。
