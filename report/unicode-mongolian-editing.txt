-- 第 4 部分：结论 --
================================================================================================
1) 字素簇：
   - 蒙文字母本身 Lo/Other，彼此不合并 -> 一词 N 个字母 = N 个光标位。
     这与拉丁文一致，光标可落在字母之间（字母本身是独立字素）。
   - FVS1-4（U+180B-D/180F）GCB=Extend -> 黏附前一字母，编辑器中
     绝不能单独删除/移动光标到 FVS 与字母之间，否则破坏字形选择。
   - Baluda(U+1885/6)、Dagalga(U+18A9) 同为 Extend，须与其基字符合并处理。
   - U+180E GCB=Control -> 是唯一会“切断”字素簇的蒙文控制符。

2) 断行：
   - 蒙文字母 LB=AL，AL x AL 禁止断行 -> 连续字母串内部没有断行点。
     传统蒙文不用空格分词，因此一个长词就是一个不可断的整体。
   - U+180E LB=GL（不换行黏合）-> 其两侧一律不得断行，
     说明它在标准中就是“词内”分隔符，不是词间分隔符。
   - U+1802/1803/1808/1809 LB=EX -> 依禁则不得出现在行首。
   - U+1804/1805 LB=BA -> 其后允许断行。
   - U+1806 LB=BB -> 其前允许断行。
   - 唯一自然断行点是 ASCII 空格（LB=SP）与上述标点。

3) 连接类型（蒙文独有）：
   - 125 个码位 JT=Dual_Joining、U+180A JT=Join_Causing、7 个 JT=Transparent。
   - 这是 Unicode 为蒙古文专门定义的连接模型，与阿拉伯文同机制但取值独立。
