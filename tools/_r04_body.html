这一篇讲国际音标（IPA）。

符号表哪儿都能查 —— 完整的官方全图就在 assets/IPA_Deja_2015.pdf（2015 修订版）。 所以本篇不背符号，只讲四件事：

  • 它不是「英语音标」 —— 国内教材说的音标是另一套东西
  • 同一个符号，在不同体系、不同语言里可能指不同的音 —— 最典型的就是 /e/
  • 同一个音，在不同语言里的「地位」不一样 —— 这是普通话和英语最大的分歧点
  • 带斜杠和带方括号是两种不同的标音 —— 一个记「能区别意义」，一个记「实际怎么读」

1IPA 是什么

一句话

IPA 是一套给「所有语言」用的记音符号：一个符号只表示一个音， 一个音只用一个符号。

全称 International Phonetic Alphabet，中文译作国际音标 （注意：不要和数学里那个「国际音标」的简称混淆，那是另一回事）。 由国际语音协会在 1888 年制定，此后多次修订 —— 本篇参考的是 2015 修订版的官方全图。

它要解决的问题：字母记不下音

只用字母表来写发音，永远说不清。三个例子：

现象例问题
同一个字母，多个音 英语 a：cat / car / cake 三个完全不同的元音，写出来一模一样
同一个音，多种拼法 英语 see / sea / piece / me 四个拼法，读音是同一个
字母和音完全错位 汉语拼音 q（七）、x（西）、zh（知） 不认识这套方案的人，看到 q 会读成 [k] 或 [kw]

IPA 的答案很直接：给每个音造一个专用符号，跟任何语言的拼写规则脱钩。

原则含义
一音一符任何一个音，都能找到唯一一个符号来写
一符一音任何一个符号，在任何语言里都读同一个音

所以它是跨语言的：英语、普通话、法语、斯瓦希里语， 都用同一套符号来记 —— 当然也能用来记回鹘蒙文的读音。

2先认识「音位」：后面所有比较的地基

这一节不涉及新符号，但不先弄清它，后面几节会看不懂。

概念 · 音位（phoneme）

一种语言里，能区别意义的最小语音单位。

检验方法只有一条：换掉它，词义会不会变？ 会变，它就是独立的音位；不会变，它只是同一个音位的变体。

最小对立对（minimal pair）

找两个只差一个音的词，如果意思不同，那一个音就是音位：

语言最小对立对说明
英语 pat / bat p 与 b 只差清浊，意思就不同 → 清浊是英语的音位对立
普通话 爸 ba / 怕 pa [p] 与 [pʰ] 只差送气，意思就不同 → 送气是普通话的音位对立
普通话（反例） 八 ba / 吧 ba 声调不同意思不同 → 声调是普通话的音位

关键：同一组音，在不同语言里地位不同

「送不送气」这件事，在两种语言里的身份完全不一样：

  • 普通话里它是音位：[p] 和 [pʰ] 是两个独立的音， 换一下就从「爸」变成「怕」。
  • 英语里它不是音位：只是同一个 /p/ 在不同位置的两种读法 —— 词首送气（pin [pʰɪn]），s 后面不送气 （spin [spɪn]）。换掉不改变词义，所以英语母语者 听不出这个差别。
这就是「口音」的来源

母语里不构成对立的差别，耳朵会自动忽略。 中国人听英语的 pin/spin 觉得「都是 p」，英语母语者听普通话的「爸/怕」 觉得「都是 ba」—— 反过来也一样。

不是听不清，是那套对立在母语里不存在。

记住这个区别，第 5 节的 /e/、第 7 节的清浊与送气，就都是同一件事的不同侧面。

4「英语音标」不是 IPA

国内教材里说的「英语音标」，通常指 DJ 音标或 KK 音标； 再加上每个中国学生都熟悉的汉语拼音。这四套东西的关系是：

DJ KK汉语拼音IPA
全称 Daniel Jones 一系 Kenyon & Knott 一系 《汉语拼音方案》 International Phonetic Alphabet
面向 英式发音（RP） 美式发音（GA） 普通话 所有语言
覆盖 只覆盖英语 只覆盖英语 只覆盖普通话 人类语言的可能发音
和 IPA 的关系 借用 IPA 符号 + 英语约定 借用 IPA 符号 + 英语约定 基本不用 IPA 符号，另起一套拉丁字母方案 就是符号表本身
符号数量 教材常说 48 个 教材常说 48 个 声母 21 + 韵母 39 左右 上百个
关键区别：一个是「全集」，其余是「为一种语言定制的子集」

DJ / KK 是对 IPA 的选择性使用 —— 挑出英语需要的符号， 再加上一些为英语方便的写法；汉语拼音则基本另起一套， 用普通拉丁字母去逼近普通话的音。

所以看到「国际音标 48 个」要立刻反应过来：那是英语的音标数， 不是 IPA 的符号数。

5一个符号，三种音：/e/

这是本篇最值得记住的一件事。同一个字母 e， 在三套体系里指的是三个不同的音。

先看 IPA 的元音图

元音不是按「谁跟谁像」排的，而是按舌头的位置排的： 竖轴是开口度（上闭下开），横轴是舌位前后（左前右后）。

元音舌位图（示意，只画了与本篇有关的几处）。 竖轴越往下嘴张得越大，横轴越往右舌根越靠后。 /e/ 与 /ɛ/ 差在「半闭」「半开」这一档。

三个 e，三处读音

写法指的是 实际舌位例
IPA /e/ 国际音标表上的那一个点 半闭 · 前 · 不圆唇
（close-mid front unrounded）		 法语 été 的结尾、西班牙语 mesa 的 e
英语 bed 的元音 英语的 DRESS 元音 半开 · 前 · 不圆唇
在 IPA 里是 /ɛ/		 bed、pen、said
汉语拼音 e 「饿」「哥」的那个韵母 后半高 · 不圆唇
在 IPA 里是 [ɤ]		 饿、哥、喝
英语教材里那个 /e/，其实是 /ɛ/

英语 bed 的元音，舌位在 IPA 的半开那一档，按 IPA 该写 /ɛ/。但英式词典的 DJ 传统习惯把它写作 /e/， 而 KK 音标写 /ɛ/。

所以「英语音标里的 /e/」并不是 IPA 图上那个 /e/ 的位置 —— 它是借了这个符号，去记一个更低的音。这是约定，不是笔误。

反过来也成立：看到英语词典里的 /e/，不要拿 IPA 的 「半闭前」去套，那会读得偏高。

以后看到 /e/，先问三句：
① 这是哪套体系的写法（IPA / DJ / KK / 拼音）？
② 记的是哪种语言的音？
③ 用的是宽式还是严式（第 11 节）？

汉语拼音是拼写方案，不是标音方案 —— 它的字母读音与 IPA 完全对不上。 用 IPA 记普通话，才看得清它「到底怎么发音」。

它们的韵母在拼音里都写作 i，但实际是两个不同的舌尖元音 [ɻ̩] 与 [ɹ̩]，舌位前后不同。 拼音为了少用字母把它们合并了 —— 这正是「拼写 ≠ 标音」的典型例子。

声调：IPA 也有符号

普通话有四个声调加轻声。IPA 用五度制的调符记录音高曲线 （数字 1 最低、5 最高）：

字拼音 调类五度值IPA
妈mā阴平（一声）55 [ma˥˥]
麻má阳平（二声）35 [ma˧˥]
马mǎ上声（三声）214 [ma˨˩˦]
骂mà去声（四声）51 [ma˥˩]
吗ma轻声— 不标调符，或标 0

四个「ma」字音完全一样，只有调不同，意思就全变了 —— 这就是第 2 节说的「音调在普通话里是音位」。

7普通话 vs 英语：清浊还是送气

这是中国人学英语、外国人学汉语，最核心的一处错位。

英语靠「清浊」
pat  [pʰæt]  清
bat  [bæt]   浊  ← 声带振动

spin [spɪn]  不送气
pin  [pʰɪn]  送气
↑ 送气与否不区别意义
  是同一个 /p/ 的两种读法
普通话靠「送气」
爸  [pa⁵¹]   不送气
怕  [pʰa⁵¹]  送气  ← 有气流

八  [pa⁵⁵]   送气与否
吧  [pa]          ← 声调
↑ 普通话没有清浊对立
  b 从来就是清音 [p]

三路对立：再加一门韩语

同一个部位（双唇塞音），三种语言切分方式完全不同 —— 这是语音学课本最爱用的例子：

语言几路对立 怎么分例
英语两路 清 / 浊 pat [pʰæt] / bat [bæt]
普通话两路 不送气 / 送气 爸 [pa] / 怕 [pʰa]
韩语三路 平音 / 紧音 / 送气 ㅂ [p] / ㅃ [p͈] / ㅍ [pʰ]
所以中国人说英语的 b，听起来像 p

普通话的 b 是不送气清音 [p]，不是英语的浊音 [b]。中国人按拼音习惯去读英语 bat， 读出来接近 [pæt] —— 在英语里就是 pat。

反过来，英语母语者读「爸」，会把不送气的 [p] 听成 /b/，于是「爸」听起来像「ba」而不是他们期待的「pa」。 双方都不是听不清，是那套对立在母语里不存在。

元音上的另一处错位：长短与松紧

英语普通话
有没有长短对立 有：ship [ʃɪp] / sheep [ʃiːp] 没有：元音长短不区别意义
单元音数量 RP 约 12 个 约 7 个（a o e i u ü er）
双元音 约 8 个（face / go / boy …） 有（ai ei ao ou），但滑动幅度通常更小
音节尾 可以 -p -t -k -m -n -ŋ -l 等 只有 -n 与 -ng，没有其他辅音收尾

最后一条最实用：普通话没有 -t -k -p 收尾， 所以英语 bat / back / bap 的结尾，中国学生常常读不出区别， 或者干脆加一个元音变成「ba-te」。

8同形陷阱：这些符号不是你以为的那个音

IPA 用的是拉丁字母的外形，但读音与英语拼写、汉语拼音都没关系。 下面这几个最容易踩：

符号在 IPA 里是 常被误当成正确例子
x软腭擦音（舌根摩擦） 拼音 x 是 [ɕ]（龈腭擦音） 德语 Bach、普通话「喝」的 h
q小舌塞音（比 k 更靠后） 拼音 q 是 [tɕʰ]（七） 阿拉伯语、因纽特语；普通话没有这个音
c硬腭塞音 拼音 c 是 [tsʰ]（次） 匈牙利语 tyúk；普通话没有
j硬腭近音（等于 y 的音） 英语字母 j 是 [dʒ] 德语 ja、拼音 ye 的 y
r舌尖颤音（打嘟噜） 英语 r 是 [ɹ]（近音，不颤） 西班牙语 perro、意大利语 roma
ɾ闪音（弹一下） — 西班牙语 pero、日语 ラ行、美式英语 butter 的 tt

y前高圆唇（ü） 英语字母 y 是 [j] 或 [aɪ] 拼音 ü、法语 tu、德语 über
一句话记法

IPA 的字母只借了「形」，没借「音」。 看到一串 IPA，按表读音值，别按英语或拼音的习惯读。

每种语言的「难」都落在它独有的那几路对立上：

10宽式与严式：两种标音，两种括号

同一句话，可以记得粗，也可以记得细。IPA 用括号区分这两种记法。

宽式标音（broad） 严式标音（narrow）
括号 斜杠 / / 方括号 [ ]
记什么 只记能区别意义的单位（音位） 记实际发出来的音，包括各种细节（音素）

普通话 爸 /pa/ [pa̠˥˩] —— 元音略靠后、声调 51
普通话 怕 /pʰa/ [pʰa̠˥˩]
谁在用 词典注音、教学、音系描写 语音学研究、方言调查、纠音
严式靠的就是附加符号

第 3 节表里的「附加符号」那一块，唯一的用途就是把宽式细化成严式。

常见的几个：ʰ 送气 · ̥ 清化 · ̹ 更圆唇 · ̜ 更不圆唇 · ̞ 略低 · ̝ 略高 · ̈ 央化 · ̩ 成音节 · ː 长。

回到 /e/：那「差一档」的争论其实在这里

英语 DRESS 元音到底算 /e/ 还是 /ɛ/， 一部分原因就是宽式与严式的要求不同：

  • 宽式只要一个能对立的符号，写 /e/ 还是 /ɛ/ 都是体系内的约定，只要全篇统一、不与别的音冲突即可。
  • 严式必须落到具体音值，于是出现 [e̞]（比 /e/ 略低）或 [ɛ̝]（比 /ɛ/ 略高）—— 因为它其实就在两者之间。

所以「英语的 /e/ 到底是什么音」这个问题，答案取决于你要多严。

两种括号不能混用

/ / 里不要塞细节符号，[ ] 里不要省略你听到的东西。 混着写，等于既没说是音位、也没说是音素。

11严式能看出宽式看不出的东西

三个真实场景，说明「多记一点细节」到底有什么用。

① 同一个音，不同口音

英语 little 的中间那个 t：

口音严式发生了什么
英式 RP[ˈlɪtl̩]仍是 [t]，词尾成音节
美式 GA[ˈlɪɾl̩]在两元音之间，t 变成闪音 [ɾ]
伦敦土话[ˈlɪʔo]变成喉塞音 [ʔ]，甚至整个音节塌缩

宽式都写 /ˈlɪtl/ —— 三者的差别只有严式才记得下。

② 儿化：一个字在语流里变形

普话「儿」单念是 [ɚ]，但作儿化后缀时，它会跟前面的韵母融合：

写法严式变化
花儿 huār[xwaɻ]只加卷舌色彩
点儿 diǎnr[tjɐɻ]韵母被压缩，元音也变了
事儿 shìr[ʂɻ̩ɻ]舌尖元音后接卷舌

这种「加一个后缀导致前面整个韵母变形」的过程，宽式的 /ɚ/ 根本表达不出来。

③ 词典为什么不写严式

因为严式没有唯一答案。同一个人说话，重读与轻读的音值都不一样； 不同发音人差别更大。所以词典只给音位层面的宽式， 让所有人对得上号。

实用建议

教学、查词、写文档用宽式（/ /），稳定、可比、不依赖发音人。

纠音、方言调查、写论文用严式（[ ]），才能把差别写清楚。

最忌讳的是混着用：在一张表里既有 / / 又有 [ ] 而不说明，读的人无法判断哪些是硬结论。

12对本项目有什么用

回鹘蒙文的读音描述，用 IPA 最不容易出歧义。

  • 拉丁转写 ≠ 记音。转写是文字层面的对应（一个字母换一个字母）； 记音是语音层面的记录（那个字母实际怎么读）。T01 讲的联合蒙文转写 属于前者；要描述「这个字母听起来像什么」，就得用 IPA。
  • 别用「像英语的 x」来描述发音。英语本身就有多种口音， 而且「像」这种说法没法验证。写成 IPA，谁读都是同一个音。
  • 写文档时至少标清宽严。音位对照用 / /， 记某位发音人的实际读音用 [ ]。
  • 注意别拿汉语拼音去套。第 6 节那张声母表已经说明： 拼音的字母读音与 IPA 对不上，q x c 尤其容易让人读错。

13一页速查

概念一句话
IPA 跨语言的记音符号，一音一符、一符一音；与具体语言无关
音位 能区别意义的最小语音单位；检验法只有一条：换掉它，词义变不变
DJ / KK / 拼音 为英语或普通话定制的方案，不等于 IPA
/e/ IPA 里是半闭·前·不圆唇；英语 bed 那个音在 IPA 里是 /ɛ/
清浊 vs 送气 英语靠清浊区分 pat/bat； 普通话靠送气区分 爸/怕
拼音的 b d g 是不送气清音 [p t k]，不是英语的浊音 [b d g]
拼音的 ü [y]，前高圆唇 —— 英语没有这个音
/ / 宽式标音：只记能区别意义的音，词典与教学常用
[ ] 严式标音：记实际发音细节，靠附加符号细化
附加符号 把宽式变严式的工具：送气 ʰ、清化 ̥、 略低 ̞ …
本篇要记住的四句话
  1. IPA 不是「英语音标」：DJ / KK / 拼音都是为单一语言定制的子集。
  2. 同一组音在不同语言里地位不同 —— 送气在普通话是音位、在英语只是变体。这是口音的根源。
  3. 同一个符号可能指不同的音 —— 最典型的是 /e/；x q c r 也全是陷阱。
  4. 斜杠与方括号是两种要求：/ / 记音位， [ ] 记细节；混用就说不清了。
